# 트랙맨 전용 레슨 성과 리포트 앱 — B2B 상용화 플랜

> 2026-07-10 작성. GDR(골프존)·TrackMan 공식 생태계·국내외 경쟁 서비스 웹 리서치(출처 하단)를
> 종합한 벤치마킹 결과와, 상용화를 위한 구조 로드맵.

---

## 1. 포지셔닝 (한 문단)

**"트랙맨 iO가 설치된 골프 아카데미가, 회원에게 카카오톡 링크 하나로 보내는
레슨 서사 중심 성과 리포트."**
트랙맨 공식 생태계는 강력하지만 회원이 ①트랙맨 계정 생성 ②앱 설치 ③시설의 유효
소프트웨어 구독이 모두 갖춰져야 리포트를 받고, 리포트도 데이터 나열 중심이라
레슨 맥락(코치 총평·다음 과제)과 한국형 전달(카톡)이 없다. GDR은 이 폐쇄 루프를
완성했지만 골프존 시뮬레이터 전용이다. 우리는 **무계정·무설치(링크로 열림) +
코치 코멘트·PT 데이터가 결합된 레슨 일지형 리포트 + 카톡 전달**로 그 틈을 판다.
공식 앱과 지표·시각화 문법은 맞추고(신뢰), 전달 경로와 맥락에서 이긴다(차별화).

## 2. 벤치마킹 — 이번에 반영 완료 ✅

| 탄착군(dispersion) 산점도 + 해석 문구 | GDR 탄착 분석 · TrackMan 다이내믹 리포트 | 클럽별 탄착군 SVG 산점도 + "탄착군 15m 이내 — 상급자 수준" 자동 해석 |
| 세션별 추이 그래프 | GDR 연습현황 · 짐데이 전후비교 | 성장 그래프(드라이버 캐리 세션 평균 추이) 신설 |

| 동기화·미디어 안정성 | GDR 앱 최다 불만 지점 | R2 업로드 3회 재시도 + 실패 배지 + 수동/부팅 재업로드 |
| 원자료 비대칭 노출 원칙 | TrackMan Portal (코치=원본, 학생=공유본만) | 녹음 원문은 관리자 보관함 전용, 지도자·회원 화면에서 숨김 |
| 화이트라벨 구조 | 바디코디 브랜디드 앱 | config.js BRAND/INSTRUCTORS/BAYS/PASSWORDS 분리 |

## 3. 벤치마킹 — 다음 단계 로드맵 🗺

우선순위순. (난이도: 리서치 기준)

1. **카카오 알림톡 자동 발송** (medium) — 리포트 링크를 수동 카톡 공유에서
   알림톡 자동 발송으로: "레슨 종료 n시간 후 리포트 도착", "이용권 만료 7일 전
   성과 요약+재등록 안내". 단가 건당 ~8원. 선행: 카카오 비즈채널 + 템플릿 심사.
2. **월간 리포트 자동 발행** (medium) — 월말에 세션 수·지표 추이·베스트 영상·코치
   코멘트를 묶은 URL 자동 생성. GDR의 재등록 유도 핵심 장치.
3. **세션 종료 시 리포트 자동 생성** (low) — TrackMan Automatic Report Sharing
   벤치마킹: 코치가 잊어도 리포트가 쌓이고, 검수 후 발송.
4. **베스트샷 자동 큐레이션** (low) — 세션마다 최고 스매시/캐리 샷 영상을 대표로
   자동 지정 (GDR 나스모 방식).
5. **아웃라이어 제외 + 지표 토글** (medium) — 공유 리포트에서 미스샷 숨기기,
   표시 지표 선택 (TrackMan 다이내믹 리포트 문법).
6. **표준화 스킬 테스트** (medium) — 월 1회 '측정의 날'(7i 10구+드라이버 10구)
   점수화 → 성장 그래프 연결. TrackMan Combine의 경량판. PT 체력 측정과 결합한
   통합 점수는 트랙맨이 못 하는 우리만의 영역.
7. **등급 벤치마크 비교** (medium) — 투어/핸디캡 그룹 평균 대비 내 위치 게이지
   ("다음 등급까지 드라이버 캐리 +12m").
8. **레슨 예약 경량 모듈** (high) — config로 on/off. 지점별 요구가 갈리므로 옵션.
9. **운영자(시설주) 대시보드** (high) — GDR Manager/GSM 벤치마킹: 지점별 세션 수·
   리포트 발송 수·베이 가동률·지도자별 성과. 회원 앱과 별도 상품으로 판매 가능.

## 4. B2B 필수 구조 요구사항

리서치에서 센터들이 실제 요구하는 것으로 확인된 항목:

- **브랜딩 커스텀** ✅ — config.js BRAND 블록으로 완료. 로고 파일(assets/)만 교체.
- **테넌트(센터) 분리** — 현재: 센터당 Supabase 프로젝트+R2 버킷+GitHub Pages 배포
  1세트 (config.js만 다름). 초기 판매엔 충분하고 데이터가 물리적으로 분리되어
  계약상 유리. 지점 수가 늘면 멀티테넌트 백엔드로 전환.
- **권한 모델** — 현재 4단(관리자/지도자[프로·트레이너]/인포데스크/회원링크).
  TrackMan의 Player/Coach/Facility 3뷰와 동형. 회원은 "공유된 리포트만" 보는
  비대칭 원칙 유지.
- **데이터 소유권** ✅ — CSV 내보내기 + JSON 백업/복구. 계약서에 "센터 데이터는
  센터 소유, 해지 시 전체 내보내기 제공" 명문화 근거.
- **보안 강화 (판매 전 필수)** —
  ① Supabase RLS 읽기전용 전환 + 쓰기 프록시(/db) 활성화 (worker/보안_읽기전용_전환가이드.md 준비됨)
  ② 비밀번호를 localStorage 평문 → 서버 검증으로 이전
  ③ 리포트 링크에 만료/토큰 옵션
  ④ **녹음 원문 서버측 차단** — 현재 관리자 전용 숨김은 UI 계층이다.
     loadAll 이 원문(sessions.supplement)을 모든 기기로 내려주고 anon key 로도
     조회 가능하므로, 판매 전에 원문을 별도 컬럼/테이블로 분리하고 RLS 로 anon
     읽기를 차단, 관리자 열람은 워커(/db) 경유 온디맨드 조회로 전환할 것.
     (내부 4인 운영에서는 현 구조로 충분 — 외부 판매 시 필수)
- **초기 설정 패키지** — 트랙맨 PC 에이전트 설치(bat 원클릭, 준비됨) + config 작성
  + 지도자 계정 세팅. "설치 1시간" 온보딩이 세일즈 포인트.

## 5. 가격 모델 참고 (리서치 근거)

- 국내 피트니스 CRM 앵커: 월 3~10만원대 (바디코디 2년 약정 월 37,800원,
  화이트라벨 앱은 상위 요금제 차별점, 멀티지점 통합계정 월 +1만원).
- 글로벌 론치모니터 소프트웨어 구독: 연 $130~600.
- 제안: **기본(리포트+수업센터) 월 5~7만원 / 프리미엄(센터 브랜딩+알림톡 자동화)
  월 10~15만원 / 지점 추가당 +α**. 트랙맨 iO 도입 센터(하드웨어에 수천만원 지출)
  대상이라 가격 저항 낮음. 알림톡 원가(건 8원)는 마진에 흡수 가능.

## 6. 기술 구조 현황과 재구성 방향

```
현재 (센터 1곳 = 1세트)
  트랙맨 iO PC ─ 에이전트(Node) ─▶ Supabase(데이터) + R2(영상) ─▶ PWA(GitHub Pages)
                                        └ Cloudflare Worker (R2 프록시·AI·STT·/db)
```

- **유지**: 에이전트 무간섭 원칙(읽기전용, PC 원본 미삭제), PWA 오프라인 안전망,
  링크형 리포트(report.html).
- **단기 재구성(판매 1~3호점)**: config.js 화이트라벨(완료) + 센터별 배포 스크립트
  (Supabase 스키마 자동 적용 + Worker 배포 + Pages 배포)를 만들어 "신규 센터 1시간
  개통"을 표준화.
- **중기(5호점~)**: Worker /db 프록시를 전면화해 anon 쓰기 차단, 리포트 발송 로그
  테이블 추가(발송·열람 추적 → 재등록 전환률 리포트), 알림톡 발송 워커.
- **장기**: 운영자 대시보드 분리 상품화, 멀티테넌트 컨트롤 플레인.
