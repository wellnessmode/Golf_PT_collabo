## (선택) 커스텀 도메인 — report.nationalgym.kr

nationalgym.kr 도메인을 보유하고 계시므로 이렇게 연결하면 완전한 자체 브랜드 주소가 됩니다:

1. Cloudflare 대시보드 → **Add a site** → `nationalgym.kr` 추가 (Free 플랜)
2. Cloudflare 가 알려주는 **네임서버 2개**를 도메인 등록업체(가비아/후이즈 등) 관리 페이지에서 교체
   - 기존 홈페이지·메일(MX) 레코드는 Cloudflare 가 자동으로 불러오지만, 교체 후 한번 확인 권장
3. 활성화되면(보통 몇 시간): Workers → `golf-pt-storage` → **Settings → Domains & Routes**
   → **Add → Custom domain** → `report.nationalgym.kr` 입력
4. `config.js` 에서 `REPORT_BASE` 주석 해제:
   ```js
   REPORT_BASE: 'https://report.nationalgym.kr',
   ```
5. 이후 [리포트 공유] 링크가 `https://report.nationalgym.kr/r/...` 로 발급됨
