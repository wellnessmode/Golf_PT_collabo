## 0. 한 줄 결론

**레슨북에는 외부 프로그램이 데이터를 직접 가져갈 수 있는 공식 통로(API·웹훅·캘린더 연동)가 없습니다(공개 자료 기준, 확인된 것 없음).** 확인된 유일한 공식 출구는 **센터 PC 프로그램(HPOS)의 "엑셀 내려받기"** 입니다. 따라서 당장은 **"엑셀 내려받기 → 우리 앱에 업로드 → 자동 대조"** 방식을 시작하고, 동시에 **개발사에 정식 연동을 문의**하는 두 갈래 진행을 추천합니다.

## 1. 레슨북이란

레슨북은 골프·필라테스·PT 등 1:1 레슨/그룹 수업의 **예약·스케줄·회원권 횟수 관리 앱**입니다. 운영사는 **주식회사 레슨북**(2020년 7월 (주)포인트뱅크에서 분사, 경기 성남시 판교 알파타워 902호)이며, 앱스토어 게시자는 여전히 **POINTBANK Corp / J3LAB** 명의이고, 홈페이지 하단에는 **제이쓰리랩(주)** 로 표기되어 있어 세 이름이 섞여 있습니다(계약 시 사업자명 확인 필요). 구성은 (1) 회원·강사·센터장용 모바일 앱(안드로이드/아이폰), (2) 센터 PC용 **윈도우 설치형 프로그램 'HPOS'**, (3) 키오스크·타석제어·QR 출입(스마트레슨북), (4) 별도 출석용 앱 '레슨북 출결'입니다. 핵심 기능은 예약/취소/변경, 강사의 **완료·결석·취소 처리에 따른 회원권 자동 차감**, 카카오 알림톡·앱 푸시 자동 발송, 강사가 남기는 '레슨기록'(사진·영상 첨부), 강사수당 자동 정산, 앱 내 결제(KICC EasyPay)이며 2026년 6월에는 전자계약서 기능도 추가될 만큼 활발히 업데이트 중입니다. 골프존 GDR아카데미·트랙맨 스튜디오 등 골프연습장 도입 사례가 많습니다. **브라우저로 여는 관리자 웹은 확인되지 않았고**, PC 관리 도구는 윈도우 프로그램(HPOS)입니다(가이드 한 곳에 'HPOS Web메뉴'라는 표현이 있으나 주소는 찾지 못함).

### 경로 1. HPOS 엑셀 내려받기 → 우리 앱에 업로드 → 자동 대조 (추천 1순위)

| 실행 난이도 | 안정성 | 약관 위험 |
|---|---|---|
| **낮음** (우리 앱에 '엑셀 업로드 + 대조' 화면만 만들면 됨, 개발 1~3주 **추정**) | **중간** (사람이 주기적으로 내려받아야 하므로 빠뜨리면 공백 발생) | **없음** (레슨북이 공식 제공하는 기능을 그대로 사용) |

- **누가 무엇을**: 데스크 직원 또는 원장이 매일 마감 때(또는 주 1회) 센터 PC의 HPOS → 예약현황관리 → 기간 지정 → '레슨예약현황' 탭 → 우측 상단 '엑셀' 버튼 → 파일 저장 → 우리 앱 관리자 화면에 업로드. 개발팀은 업로드 화면, 전화번호 기준 회원 매칭, 날짜/상태 해석, "완료인데 일지 없음" 목록 자동 생성 기능을 만듭니다.
- **우리 앱이 얻는 데이터**: 회원·강사·일시·상태(완료/결석/취소/노쇼) 단위의 레슨 이력, 회원별 기간별 이용현황. (엑셀의 정확한 컬럼 구성은 원문을 못 열어 **미확인** — 첫 파일을 실제로 받아 보고 확정해야 합니다. 검색 요약상 접수일·수정일·예약상태·처리상태·시설명·강사명·회원정보·시작/종료시간·체크인시간이 들어 있다는 언급이 있으나 신뢰도 낮음.)
- **주의점**: (1) 엑셀 기능은 **센터버전(HPOS 설치 센터)** 에서만 확인됨. 우리 스튜디오가 앱만 쓰고 HPOS가 없다면 고객센터에 엑셀 반출 방법을 먼저 물어야 합니다. (2) 레슨기록 정렬이 연도를 무시하는 버그 사례가 있으므로 날짜는 우리 쪽에서 직접 해석해야 합니다. (3) 프로들이 '완료' 처리를 안 하면 데이터에 안 잡히므로 운영 규칙이 필요합니다.

## 4. 추천과 당장 할 일

### 추천 1순위: 경로 1(엑셀 대조)을 즉시 시작 + 경로 2(개발사 문의)를 병행

이유:
1. 조사에서 **실제로 검증된 유일한 데이터 출구**가 엑셀 내려받기입니다(공식 가이드 3개 페이지가 일관되게 명시).
2. 약관 위험이 없고, 개발사 답변을 기다리지 않아도 **2~3주 안에(추정)** 가동할 수 있습니다.
3. 엑셀을 한 번 받아 보면 컬럼 구조를 알게 되므로, 나중에 개발사와 정식 연동을 협의할 때도 "이 항목들을 자동으로 주세요"라고 구체적으로 요구할 수 있습니다.
4. 정식 연동이 성사되면 업로드 단계만 자동화로 바꾸면 되므로 앞서 만든 대조 로직이 그대로 재사용됩니다.

보완책(비기술): 우리 앱에 일지를 쓰는 행위 자체를 프로의 '레슨 완료 확인'으로 삼고, 레슨북 엑셀은 **빠진 것을 잡아내는 검증용**으로만 쓰면 의존도가 줄어듭니다.

### 대표가 당장 할 수 있는 행동 (체크리스트)

1. 센터 PC에서 HPOS → 예약현황관리 → 최근 1개월 → '엑셀' 버튼으로 **파일 하나를 실제로 내려받아 개발팀에 전달** (컬럼 확인이 모든 설계의 출발점).
2. 우리 스튜디오가 **센터버전(HPOS)** 인지, 앱만 쓰는지 확인. 앱만 쓴다면 고객센터에 "엑셀로 예약현황을 받을 방법"을 먼저 문의.
3. 아래 문구로 **개발사에 연동 문의** 발송 (앱 1:1문의 + 이메일 동시 발송 권장).
4. 프로들에게 **레슨 끝나면 반드시 '완료' 처리** 하도록 규칙 공지(안 하면 어떤 방식이든 데이터에 안 잡힘).
5. 레슨북 **이용약관 원문**을 앱 설정 화면에서 캡처해 개발팀에 전달(자동화 금지 조항 확인용).
