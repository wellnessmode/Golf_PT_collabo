# 트랙맨(TrackMan) 실데이터 연동 — 방법 & 준비 가이드

> 목표: 라이브 세션의 "굿샷(데모)"을 **진짜 트랙맨 측정값 + 스윙 영상**으로 자동 교체.
> 현재는 굿샷 버튼이 모의 데이터를 만들지만, 이 단계가 끝나면 베이 PC의 트랙맨이
> 실제로 측정한 샷이 활성세션 회원에게 자동으로 들어옵니다.

## 0. 변하지 않는 원칙
- 에이전트는 TPS를 **읽기만** 한다 (무간섭). TPS에 명령·쓰기·UI 변경 일절 없음 → 연습 중인 회원 화면에 영향 0.
- 모든 샷은 **bay_id 기준**으로만 귀속 ("최근 누른 사람" 같은 추측 매칭 금지).
- 활성세션 없는 베이의 샷은 저장 안 함(폐기 로그만).

## 1. 전체 구조
```
[베이 PC: 트랙맨 + TPS]
   ├─ TPS가 만드는 샷 데이터 (CSV / 로컬파일) ──┐
   └─ 스윙 영상 파일 ─────────────────────────┤
                                              ▼
                                   [로컬 에이전트]  (우리가 설치, 백그라운드, 읽기전용)
                                              │  HTTPS
                                              ▼
                              [R2 워커 /shot · /video]   ← 키는 워커 시크릿
                                              │
                                  ┌───────────┴───────────┐
                                  ▼                       ▼
                       [Supabase shot_events]        [R2 영상 저장]
                                  │
                                  ▼
                    [앱: 라이브 세션 → 성과 리포트 자동 반영]
```

## 2. 트랙맨 데이터를 꺼내는 3가지 방법 (접근성 순)

### 방법 A — CSV 내보내기 감시 ⭐ 시작 추천 (라이선스·비용 불필요)
- TPS Shot Analysis에서 샷을 **TrackMan CSV**로 내보낼 수 있음 (40+ 파라미터: Club/Ball Speed, Smash, Carry, Total, Launch, Spin, Club Path, Face Angle, Side, Side Total, Landing Angle 등).
- 에이전트가 내보내기 폴더를 감시 → 새 CSV → 파싱 → 전송.
- 장점: 추가 계약·비용 0, **바로 가능**.
- 단점: TPS 버전에 따라 "수동 내보내기"(세션 끝에 한 번)일 수 있음. 샷별 실시간은 제한적.
- 확인 필요: 자동/예약 내보내기 지원 여부.

### 방법 B — TPS 로컬 데이터 파일/DB 감시 (실시간 가능, 비공식)
- TPS는 샷을 로컬에 저장(파일/DB). 그 위치를 찾아 실시간 감시하면 샷별 즉시 반영.
- 장점: **실시간**.
- 단점: 비공식 — 포맷이 버전마다 다르고 TrackMan 업데이트 시 깨질 수 있음.
- 확인 필요: 데이터 저장 경로/포맷 (현장 관찰).

### 방법 C — TrackMan 공식 API / Connect (가장 깔끔, 계약 필요)
- TrackMan B2B 데이터 API / TrackMan Connect — 공식 실시간 샷 데이터(webhook/API).
- 장점: 공식·안정·실시간·미래보장.
- 단점: TrackMan과 상업 계약/라이선스 + 리드타임 필요.
- 준비: TrackMan 한국 지사/담당에 데이터 API 접근 문의.

> **권장 경로:** A로 PoC를 빠르게 띄워 파이프라인 검증 → 동시에 C 문의 → 가능하면 C(공식 실시간)로 전환. B는 A/C가 막힐 때 보조.

## 3. 영상 연동
- 트랙맨/유닛이 스윙 영상을 저장하는 폴더를 에이전트가 감시 → R2 업로드 → 샷 타임스탬프와 매칭.
- 또는 베이별 카메라 + OBS/ffmpeg로 에이전트가 직접 캡처(샷 시점 전후 N초).
- 확인 필요: 영상 녹화 여부/위치/포맷, 또는 별도 카메라 설치 필요 여부.

## 4. 데이터 계약 (에이전트 → 서버, shot_events 스키마와 동일)
```json
{
  "bay_id": "bay1",
  "ts": "2026-05-30T05:12:33Z",
  "source": "agent",
  "data": {
    "club": "Driver", "clubSpeed": 103.4, "ballSpeed": 153.0, "smash": 1.48,
    "carry": 251, "total": 268, "launch": 14.1, "spin": 2710,
    "clubPath": 0.4, "faceAngle": -0.2, "attack": 1.2,
    "side": 3.1, "sideTotal": 5.0, "landAngle": 38
  },
  "video_r2_key": "bay1/2026-05-30/shot_1212.mp4"
}
```
서버(워커)가 처리: **활성세션 확인 → 그 회원에게 귀속**. 활성세션 없으면 `discarded_signals`에 폐기 기록(사고 추적용).

## 5. 준비 체크리스트 — 사장님 액션

### 5-1. 베이 PC 현장 정찰 (가장 중요, 스크린샷 부탁)
각 베이 PC에서:
1. **트랙맨 모델**: TrackMan 4 / iO / 시뮬레이터 중 무엇?
2. **TPS 버전**: 메뉴 → Help/About (스샷)
3. **TPS Settings 전체** (특히 Data / Export / Output 항목) (스샷)
4. Shot Analysis 화면에 **Export / Save as CSV** 옵션 있는지 (스샷)
5. **데이터 저장 위치**: `Documents\TrackMan`, `AppData` 등에 세션/샷 파일이 생기는지
6. **영상**: 스윙 영상이 녹화되는지, 저장 폴더/포맷
7. **자동 내보내기** 가능 여부 (아니면 수동만인지)

### 5-2. 네트워크 / PC
- 각 베이 PC가 **인터넷(아웃바운드 HTTPS)** 되는지
- **OS**(윈도우 버전), **관리자 권한**으로 백그라운드 프로그램 설치 가능한지

### 5-3. TrackMan 문의 (방법 C용, 병행)
트랙맨 담당에게:
> "우리 시설 유닛의 샷 데이터를 외부 시스템으로 **실시간/자동 내보내기** 할 수 있나요?
>  (데이터 API / TrackMan Connect / CSV 자동화) 가능 여부·비용·조건 알려주세요."

### 5-4. 베이 매핑 (고정)
- 1번타석 PC = `bay1` · 2번타석 = `bay2` · 3번룸 = `bay3`

## 6. 롤아웃 단계
1. **PoC (1베이, 방법 A)** — 1번타석 PC에 에이전트 설치 → CSV 감시 → 샷 1개가 앱 활성세션에 들어오는 것 확인.
2. **영상 연동** — 영상 1개 R2 업로드 → 리포트 영상 그리드에 실물 표시.
3. **실시간화** — 방법 B 또는 C로 샷별 실시간 전환.
4. **전 베이 확장** — 2·3번 에이전트 배포.
5. **운영 모니터링** — `discarded_signals`로 매칭 누락/오귀속 점검.

## 7. 우리가 준비할 것 (사장님 OK 시 바로 착수)
- **에이전트 프로그램** — 베이 PC용 백그라운드 앱(Windows 실행파일). 폴더 감시 → 파싱 → 전송 → 영상 업로드 → 하트비트(`bay_agents`). 무간섭·읽기전용.
- **워커 `/shot` · `/video` 인제스트 엔드포인트** — 키는 시크릿. 활성세션 매칭/폐기 로직.
- **파이프라인 시뮬레이터** — 가짜 TPS CSV로 전체 흐름(에이전트→워커→Supabase→앱)을 먼저 만들고 검증 → 현장에선 **진짜 폴더만 연결**하면 끝. (현장 리스크 최소화)

> 현장 스크린샷(5-1) 몇 장만 주시면, 진짜 TPS CSV 포맷에 맞춰 파서를 완성하고 PoC를 띄웁니다.
