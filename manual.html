2. 앱 설치 (홈 화면 추가)

매번 브라우저에서 주소를 치는 대신, 홈 화면에 아이콘으로 설치하여 앱처럼 빠르게 실행할 수 있습니다.

2.1. iPhone / iPad (Safari)

Safari에서 wellnessmode.github.io/Golf_PT_collabo로 접속합니다.
하단 공유 버튼 (□↑)을 터치합니다.
메뉴를 스크롤하여 "홈 화면에 추가"를 터치합니다.
우측 상단 "추가"를 터치합니다.
홈 화면에 "Golf PT" 아이콘이 생성됩니다.

2.2. Android (Chrome)

Chrome에서 접속합니다.
우측 상단 ⋮ (메뉴) 버튼을 누릅니다.
"앱 설치" 또는 "홈 화면에 추가"를 선택합니다.
"설치"를 누르면 홈 화면에 아이콘이 추가됩니다.
💡 설치 후 이점
  • 주소창 없이 전체화면으로 실행 (앱처럼 동작)
  • 홈 화면 터치 한 번으로 바로 열림
  • 오프라인 상태에서도 기본 화면 표시
  • iOS 다이나믹 아일랜드/노치 safe-area 자동 대응

3. 회원 등록 & 관리 (인포데스크)

3.1. 회원 유형 이해

내셔널짐 Golf PT는 두 가지 회원 유형을 관리합니다.

유형설명담당
💪 PT+골프골프 레슨 + 골프 PT 둘 다 등록한 회원프로 + 트레이너 협업
🏌️ 골프골프 레슨만 등록한 회원프로 단독 관리
ℹ️ 유형 변경 가능
나중에 PT+골프 → 골프로(또는 반대) 유형 변경 시 기존 데이터는 그대로 유지됩니다. 회원 정보 수정에서 회원 유형만 변경하면 됩니다.

3.2. 새 회원 등록 절차

인포데스크로 로그인합니다.
사이드바 하단의 + 새 회원 등록 버튼을 누릅니다.
회원 유형을 먼저 선택합니다. (💪 PT+골프 또는 🏌️ 골프)
회원 이름을 입력합니다. (필수)
연락처, 이메일, 등록일, 유효기간을 입력합니다.
골프 레슨 등록 횟수와 금액을 입력합니다.
PT+골프 유형이면 골프 PT 등록 횟수·금액을 추가로 입력합니다.
골프 프로필 — 핸디캡, 평균 타수, 목표, 주력 교정 포인트를 입력합니다. (선택)
담당 지도자를 체크로 배정합니다. (여러 명 가능)
등록 버튼을 눌러 저장합니다.
⚠️ 담당 지도자 배정 필수
담당 지도자를 배정하지 않으면 해당 프로/트레이너의 사이드바에서 회원이 보이지 않습니다. 반드시 배정해주세요.

3.3. 회원 정보 수정 / 삭제

사이드바에서 해당 회원 옆의 [수정] 또는 [삭제] 버튼을 누릅니다.
수정 — 정보 변경 후 저장. 담당자 변경 시 인수인계 카드 자동 생성.
삭제 요청 — 인포데스크가 삭제 요청 → 프로/트레이너 승인 후 완전 삭제.
💡 담당 지도자 변경 시 인수인계 자동 생성
회원의 담당자가 바뀌면 최근 10개 세션, 체형평가 주의사항, 스윙 영상 요약이 자동으로 카드로 생성됩니다. 새 담당자가 바로 확인할 수 있습니다.

4. 세션 기록 (프로 · 트레이너)

4.1. 세션 기록 추가

프로 또는 트레이너로 로그인합니다.
사이드바에서 오늘 수업한 회원을 선택합니다.
우측 상단 + 세션 기록 버튼을 누릅니다.
날짜는 자동으로 오늘 날짜가 입력됩니다. 필요시 변경 가능합니다.
담당자는 본인만 선택 가능합니다. (다른 담당자는 회색 처리)
운동 / 레슨 내용을 자유롭게 입력합니다. 또는 + 운동 빠른추가 버튼을 사용합니다.
스윙 영상 (정면/측면) 및 운동 영상을 첨부합니다. (선택)
기록 저장을 누릅니다.
ℹ️ 세션 기록 수정
저장된 세션 카드에서 [수정] 버튼으로 내용·날짜·미디어를 변경할 수 있습니다. 담당자는 변경 불가합니다.

4.2. 세션 카드 구성 요소

저장된 세션은 카드 형태로 표시됩니다.

  • 역할 태그: GOLF PRO (파란색) 또는 GOLF PT (초록색)
  • 담당자 이름 + 날짜
  • NEW 배지: 상대 담당자가 기록한 세션이 아직 확인되지 않은 경우 빨간 배지
  • 수업 내용 전문
  • 스윙 플레이어: 정면/측면 영상 (AI 스켈레톤 분석)
  • 운동 영상 썸네일
  • 수정 / 삭제 버튼

4.3. 세션 필터

회원 상세 페이지에서 세션을 역할별로 필터링할 수 있습니다.

  • 전체 — 모든 세션 표시 (기본값)
  • 프로 — 골프 프로가 기록한 세션만
  • 트레이너 — PT 트레이너가 기록한 세션만

5. 스윙 영상 분석

5.1. 영상 첨부 가이드

💡 영상 촬영 팁
  • 정면 영상: 회원 정면 약 3m 거리, 허리 기준 눈높이
  • 측면 영상: 회원 측면 약 3m 거리, 어드레스 라인과 90도
  • 밝은 환경에서 촬영 (AI가 관절을 인식하려면 충분한 조명 필요)
  • 배경이 단순할수록 인식 정확도 높음
  • 파일당 최대 100MB (자동 압축됨 1280px / 2.5Mbps)

5.2. AI 자동 분석

영상을 업로드하면 자동으로 다음이 분석됩니다 (약 10~20초 소요).

  • 🦴 스켈레톤 오버레이 — 33개 관절 실시간 추적
  • 📏 가이드라인 — 척추선, 어깨선, 골반선, 수직 기준선
  • 📊 핵심 지표 — X-Factor, 척추각, 리드암, 무릎 굴곡, 머리 이동
  • 👻 Address/Finish 유령 기준선 — 어드레스와 피니시 자세 비교
  • 📈 Trackman 스타일 A→F 요약 카드 — 좌/우 힙 이동, X-Factor, 헤드 이동 등
