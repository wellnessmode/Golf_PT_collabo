2.1. iPhone / iPad (Safari)

Safari에서 wellnessmode.github.io/Golf_PT_collabo로 접속합니다.
하단 공유 버튼 (□↑)을 터치합니다.
메뉴를 스크롤하여 "홈 화면에 추가"를 터치합니다.

2.2. Android (Chrome)

Chrome에서 접속합니다.

"앱 설치" 또는 "홈 화면에 추가"를 선택합니다.

💡 설치 후 이점

  • iOS 다이나믹 아일랜드/노치 safe-area 자동 대응

3. 회원 등록 & 관리 (인포데스크)

3.1. 회원 유형 이해

내셔널짐 Golf PT는 두 가지 회원 유형을 관리합니다.

유형설명담당
💪 PT+골프골프 레슨 + 골프 PT 둘 다 등록한 회원프로 + 트레이너 협업
🏌️ 골프골프 레슨만 등록한 회원프로 단독 관리
ℹ️ 유형 변경 가능
나중에 PT+골프 → 골프로(또는 반대) 유형 변경 시 기존 데이터는 그대로 유지됩니다. 회원 정보 수정에서 회원 유형만 변경하면 됩니다.

3.2. 새 회원 등록 절차

인포데스크로 로그인합니다.
사이드바 하단의 + 새 회원 등록 버튼을 누릅니다.
회원 유형을 먼저 선택합니다. (💪 PT+골프 또는 🏌️ 골프)
회원 이름을 입력합니다. (필수)
연락처, 이메일, 등록일, 유효기간을 입력합니다.
골프 레슨 등록 횟수와 금액을 입력합니다.
PT+골프 유형이면 골프 PT 등록 횟수·금액을 추가로 입력합니다.
골프 프로필 — 핸디캡, 평균 타수, 목표, 주력 교정 포인트를 입력합니다. (선택)
담당 지도자를 체크로 배정합니다. (여러 명 가능)
등록 버튼을 눌러 저장합니다.
⚠️ 담당 지도자 배정 필수
담당 지도자를 배정하지 않으면 해당 프로/트레이너의 사이드바에서 회원이 보이지 않습니다. 반드시 배정해주세요.

3.3. 회원 정보 수정 / 삭제

사이드바에서 해당 회원 옆의 [수정] 또는 [삭제] 버튼을 누릅니다.
수정 — 정보 변경 후 저장. 담당자 변경 시 인수인계 카드 자동 생성.
삭제 요청 — 인포데스크가 삭제 요청 → 프로/트레이너 승인 후 완전 삭제.
💡 담당 지도자 변경 시 인수인계 자동 생성
회원의 담당자가 바뀌면 최근 10개 세션, 체형평가 주의사항, 스윙 영상 요약이 자동으로 카드로 생성됩니다. 새 담당자가 바로 확인할 수 있습니다.

4. 세션 기록 (프로 · 트레이너)

4.1. 세션 기록 추가

프로 또는 트레이너로 로그인합니다.
사이드바에서 오늘 수업한 회원을 선택합니다.
우측 상단 + 세션 기록 버튼을 누릅니다.
날짜는 자동으로 오늘 날짜가 입력됩니다. 필요시 변경 가능합니다.
담당자는 본인만 선택 가능합니다. (다른 담당자는 회색 처리)
운동 / 레슨 내용을 자유롭게 입력합니다. 또는 + 운동 빠른추가 버튼을 사용합니다.
스윙 영상 (정면/측면) 및 운동 영상을 첨부합니다. (선택)
기록 저장을 누릅니다.
ℹ️ 세션 기록 수정
저장된 세션 카드에서 [수정] 버튼으로 내용·날짜·미디어를 변경할 수 있습니다. 담당자는 변경 불가합니다.

4.2. 세션 카드 구성 요소

저장된 세션은 카드 형태로 표시됩니다.

  • 역할 태그: GOLF PRO (파란색) 또는 GOLF PT (초록색)
  • 담당자 이름 + 날짜
  • NEW 배지: 상대 담당자가 기록한 세션이 아직 확인되지 않은 경우 빨간 배지
  • 수업 내용 전문
  • 스윙 플레이어: 정면/측면 영상 (AI 스켈레톤 분석)
  • 운동 영상 썸네일
  • 수정 / 삭제 버튼

4.3. 세션 필터

회원 상세 페이지에서 세션을 역할별로 필터링할 수 있습니다.

  • 전체 — 모든 세션 표시 (기본값)
  • 프로 — 골프 프로가 기록한 세션만
  • 트레이너 — PT 트레이너가 기록한 세션만

5. 스윙 영상 분석

5.1. 영상 첨부 가이드

💡 영상 촬영 팁
  • 정면 영상: 회원 정면 약 3m 거리, 허리 기준 눈높이
  • 측면 영상: 회원 측면 약 3m 거리, 어드레스 라인과 90도
  • 밝은 환경에서 촬영 (AI가 관절을 인식하려면 충분한 조명 필요)
  • 배경이 단순할수록 인식 정확도 높음
  • 파일당 최대 100MB (자동 압축됨 1280px / 2.5Mbps)

5.2. AI 자동 분석

영상을 업로드하면 자동으로 다음이 분석됩니다 (약 10~20초 소요).

  • 🦴 스켈레톤 오버레이 — 33개 관절 실시간 추적
  • 📏 가이드라인 — 척추선, 어깨선, 골반선, 수직 기준선
  • 📊 핵심 지표 — X-Factor, 척추각, 리드암, 무릎 굴곡, 머리 이동
  • 👻 Address/Finish 유령 기준선 — 어드레스와 피니시 자세 비교
  • 📈 Trackman 스타일 A→F 요약 카드 — 좌/우 힙 이동, X-Factor, 헤드 이동 등

포함 내용

  • 회원 기본 정보 (이름, 연락처, 등록일, 유효기간, 진행 현황)

8.2. 이미지 카드 (카카오톡 공유용)

회원에게 간단히 월간 레슨 현황을 카카오톡으로 공유할 때 사용합니다.

회원 상세 페이지에서 🖼️ 카드 버튼을 누릅니다.
📥 이미지 다운로드 버튼을 누릅니다.
720×960 PNG 이미지가 자동 다운로드됩니다. (예: 홍길동_레슨카드_2026-04-12.png)
사진 앱에서 해당 이미지를 열어 카카오톡으로 공유합니다.

카드 구성

  • 회원 이름, 핸디캡, 평균 타수, 목표, 주력 교정
  • 이번 달 레슨 횟수 & 최근 6회 내용
  • 전체 진행률 바 (등록 대비 사용)

9. 대시보드 & 인수인계

9.1. 대시보드 (📊 버튼)

사이드바 또는 마이페이지에서 대시보드를 열면 전체 운영 현황을 한눈에 볼 수 있습니다.

상단 통계

  • 회원 수 — 접근 가능한 회원 총 수
  • 총 세션 — 전체 세션 누적
  • 이번 달 — 당월 세션 수
  • 프로 / PT 세션 — 역할별 기록 수

하단 위젯

  • 지도자별 세션 바 차트 — 정P, 홍P, 최T, 이T별 세션 비율
  • 만료 임박 회원 — 30일 이내 유효기간 만료 경고
  • 회원별 진행률 — 레슨/PT 등록 대비 사용 현황
  • 최근 활동 15건 — 최근 세션 피드 (클릭 시 해당 회원으로 이동)

9.2. 인수인계 시스템

담당 지도자 교체 시 새 담당자가 회원 히스토리를 빠르게 파악할 수 있도록 자동 요약 카드가 생성됩니다.

자동 생성 트리거

인포데스크가 회원 정보 수정에서 담당 지도자 체크를 변경하면 자동으로 인수인계 카드가 생성됩니다.

카드 내용

  • 이전 담당자 → 새 담당자 정보
  • 총 세션 수 (프로 X회 + PT Y회)
  • Body-Swing 주의 항목 (체형평가 제한 항목)
  • 체형평가 이상 소견 요약
  • 최근 10개 세션 요약
  • 최근 스윙 영상 현황

확인 방법

회원 상세 페이지 우측 상단에 📋 인수인계 버튼이 표시됩니다. (카드가 있을 때만)
버튼 옆 숫자 배지는 히스토리 개수입니다.
클릭하면 시간순으로 모든 인수인계 카드를 볼 수 있습니다.

10. 자주 묻는 질문 (FAQ)

Q1. 비밀번호를 잊어버렸어요.

관리자 계정(admin0000)으로 로그인 후 감사 로그에서 이전 비밀번호 변경 내역을 확인할 수 있습니다. 또는 개발팀에 문의하여 초기화 요청하세요.

Q2. 회원 목록에 안 보이는데요?

프로/트레이너 계정은 배정된 회원만 표시됩니다. 인포데스크에게 담당 지도자 배정을 요청하세요. 또는 사이드바 PT+골프 / 골프 탭을 확인하세요.

Q3. 영상 분석이 안 돼요.

  • 사람 감지 불가: 조명이 어둡거나 회원이 화면 밖. 재촬영 필요.
  • 분석 대기중: 영상 로딩 지연. 🔄 재분석 버튼 클릭.
  • 캐시 문제: 플레이어 툴바 ♻ 버튼으로 캐시 무효화 후 재분석.

Q4. 데이터가 다른 기기에서 안 보여요.

Supabase 클라우드 동기화가 연동되어 있어 모든 기기에서 같은 데이터를 공유합니다. 네트워크 연결을 확인하고, 사이드바 하단 동기화 상태 배지가 "연결됨"인지 확인하세요. 오류 시 🔄 버튼을 누르세요.

Q5. 영상이 업로드되지 않아요.

  • 파일 크기가 100MB 넘으면 업로드 거부됩니다.
  • 업로드 중 저장 버튼 누르면 차단됩니다. "업로드 중" 표시가 사라진 후 저장하세요.
  • 브라우저 저장 공간 부족 시 경고가 뜹니다. 오래된 영상 삭제 필요.

Q6. 인수인계 카드는 언제 생성되나요?

인포데스크가 회원 수정에서 담당 지도자 체크박스를 변경하는 순간 자동 생성됩니다. 단순히 이름/연락처 수정 시에는 생성되지 않습니다.

Q7. 세션 기록을 수정하고 싶어요.

세션 카드의 [수정] 버튼을 누르세요. 날짜, 내용, 미디어는 변경 가능하나 담당자는 변경 불가합니다. (감사 로그에 변경 기록이 남습니다.)

Q8. 회원을 삭제했는데 복구할 수 있나요?

삭제 승인 후에는 영구 삭제되어 복구 불가합니다. 삭제 요청 → 운동지도자 승인 2단계로 구성되어 있어 실수 방지됩니다. 승인 전에는 거절로 취소 가능합니다.

Q9. 체형평가를 여러 번 기록하려면?

📸 애프터 평가 시작 버튼을 누르면 현재 평가가 히스토리로 저장되고, 새로 입력 가능한 상태가 됩니다. 히스토리는 누적되어 변화 추적이 가능합니다.

Q10. 오프라인에서도 사용 가능한가요?

PWA 설치 후 기본 화면 표시는 가능하지만, 데이터 입력/수정은 온라인 상태에서만 가능합니다. Supabase 클라우드 동기화를 위해 네트워크 연결이 필요합니다.
