# 보안 강화 — 읽기 전용 RLS 전환 가이드

현재: 공개된 anon 키로 **누구나** Supabase 전체 삭제·회원정보 덤프가 가능.
목표: anon 은 **읽기만**, 모든 쓰기는 워커 `/db`(서버 서비스 키) 경유.

> ⚠️ **순서를 반드시 지키세요.** 순서를 어기면 앱 저장이 막혀 스튜디오가 멈춥니다.
> 각 단계 후 저장/삭제가 되는지 확인하고 다음으로.

---

## 준비물
- Supabase 대시보드 접근
- Cloudflare 워커(golf-pt-storage) 접근
- `service_role` 키 (Supabase → Project Settings → API → service_role, **secret**)

---

## 1단계. 워커에 서비스 키 시크릿 추가 + 배포

1. Cloudflare → Workers → **golf-pt-storage** → Settings → **Variables and Secrets**
2. **Add** 두 개:
   - `SUPABASE_URL` = `https://cacytkmijttyeasmhvhq.supabase.co`
   - `SUPABASE_SERVICE_KEY` = (service_role 키, **Encrypt** 체크)
3. **Edit code** → 깃허브 `worker/golf-pt-storage-worker.js` 전체 복사 → 붙여넣기 → **Deploy**
4. 확인: 이 시점엔 앱/에이전트가 아직 anon 직접 쓰기라 정상 동작해야 함.

## 2단계. 앱에 프록시 URL 추가 + 배포

1. `config.js` 열어서 아래 한 줄 추가:
   ```js
   DB_PROXY_URL: 'https://golf-pt-storage.ceo-fc9.workers.dev',
   ```
   (R2_WORKER_URL 과 같은 주소)
2. 커밋·푸시 → 앱 새로고침
3. **확인**: 회원 수정·세션 저장·샷 삭제가 정상인지 테스트.
   (이제 앱 쓰기가 워커 /db 경유. 아직 RLS 는 안 조였으니 실패해도 앱은 안 깨짐)
   → 워커 로그(Cloudflare)나 저장 후 새로고침으로 반영 확인.

## 3단계. 에이전트도 프록시 경유

1. `C:\golfpt-sync\config.json` 에서 `"useDbProxy": false` → **`true`**
2. `중지.bat` → `설치_자동시작.bat` (재시작)
3. **확인**: 공 1발 → 폰에 샷 뜨는지. (에이전트가 /db 경유로 insert)

## 4단계. RLS 읽기 전용 전환 (마지막)

앞 3단계가 **모두 정상 확인**된 뒤에만:

1. Supabase → **SQL Editor**
2. `worker/supabase_rls_readonly.sql` 내용 붙여넣기 → **RUN**
3. **확인**: 앱에서 저장/삭제, 에이전트 샷 전송이 여전히 정상인지.
   - 정상 → 완료. 이제 공개 키로는 조회만 가능.
   - 저장이 막히면 → 2·3단계 프록시가 실제로 작동 안 하는 것.
     즉시 롤백: SQL Editor 에서 아래 실행(다시 개방):
     ```sql
     do $$ declare t text; begin
       foreach t in array array['members','assessments','sessions','shot_events','active_sessions','bays','reports']
       loop execute format('alter table public.%I disable row level security;', t); end loop;
     end $$;
     ```

## 롤백(비상)
- 앱: `config.js` 의 `DB_PROXY_URL` 줄 삭제 → 배포 → anon 직접 쓰기로 복귀
  (단 RLS 가 읽기전용이면 이 방법은 안 됨 — 먼저 위 SQL 로 RLS 해제)
- 에이전트: `useDbProxy: false` → 재시작

## 남은 보안 항목(추후)
- 로그인 비밀번호 평문 → 해시/워커 검증 (별도)
- R2 GET 무인증(영상 공개 URL) → 서명 URL 도입 시 (별도)
- 공유 리포트 링크 토큰화 (별도)
