# 리포트 검토 독촉 푸시 — golf-pt-push 워커 배포 (약 10분, CLI 불필요)

## 무엇을 하나

회원 링크가 있는 회원의 일지·영상이 바뀌면 앱이 그 회원을 **검토 대기**로 표시합니다.
담당 프로가 성과 리포트에서 **[검토 완료]** 를 눌러야 회원 링크에 최신 내용이 반영되는데,
이걸 안 누르면 회원은 옛 리포트를 봅니다.

앱 v9.92 부터는 두 가지로 독촉합니다.

1. **앱 안 독촉 창** — 담당자가 앱을 열 때·복귀할 때·30분마다 검토 대기 목록을 띄웁니다 (1시간 뒤 다시 가능).
   워커 없이도 바로 동작합니다.
2. **폰 푸시 알림** — 이 문서의 워커를 배포하면, 앱을 안 열어도 하루 몇 번(기본 10시·14시·19시)
   담당자 폰에 "📤 리포트 검토 대기 2명: 홍길동(3일째), 김철수(오늘)" 알림이 옵니다.
   관리자 폰에는 담당자별 요약이 옵니다.

배포 전에도 앱은 정상 동작합니다 — 워커가 없으면 "🔔 검토 알림을 폰으로 받기" 버튼이 조용히 숨겨집니다.

## 1. Supabase 테이블 만들기 (한 번)

Supabase 대시보드 → **SQL Editor** → 아래를 붙여넣고 Run.
(`supabase_schema.sql` 맨 아래에도 같은 내용이 있습니다.)

```sql
create table if not exists public.push_subscriptions (
  endpoint    text        primary key,
  user_name   text        not null,
  role        text        not null default 'pro',
  p256dh      text        not null,
  auth        text        not null,
  ua          text        default '',
  fail_count  int         not null default 0,
  last_ok_at  timestamptz,
  updated_at  timestamptz not null default now(),
  created_at  timestamptz not null default now()
);
alter table public.push_subscriptions enable row level security;
```

anon 정책은 만들지 않습니다. 워커만(service_role 키) 읽고 씁니다.

## 2. 워커 만들기

1. Cloudflare 대시보드 → **Workers & Pages → Create → Create Worker**
2. 이름을 정확히 **`golf-pt-push`** 로 → Deploy
   - 주소가 `https://golf-pt-push.ceo-fc9.workers.dev` 가 되어야 합니다 (앱 config.js 의 `PUSH_WORKER_URL`).
     다르면 config.js 값을 실제 주소로 고쳐 커밋하세요.
3. **Edit code** → 저장소의 `worker/golf-pt-push-worker.js` 내용을 전부 붙여넣기 → **Deploy**

## 3. 시크릿 등록 — 1차 (3개)

**Settings → Variables and Secrets → Add** (Type: Secret)

| 이름 | 값 |
|---|---|
| `APP_API_KEY` | 앱 config.js 의 `R2_API_KEY` 와 **같은 값** |
| `SUPABASE_URL` | `https://cacytkmijttyeasmhvhq.supabase.co` (config.js 의 SUPABASE_URL) |
| `SUPABASE_SERVICE_KEY` | Supabase → Project Settings → API → **service_role** 키 (기존 R2 워커에 등록된 것과 같음) |

## 4. VAPID 키 만들기 → 시크릿 2차 (2개)

푸시 서비스(애플·구글)에 "우리 서버가 보낸다"를 증명하는 키쌍입니다. 브라우저에서 한 번만 만듭니다.

브라우저 주소창에 (APP_API_KEY 자리에 config.js 의 R2_API_KEY 값):

```
https://golf-pt-push.ceo-fc9.workers.dev/push/genkeys?key=APP_API_KEY
```

화면에 `VAPID_PUBLIC_KEY` (87자) 와 `VAPID_PRIVATE_KEY` (43자) 가 뜹니다. **이 화면은 저장되지 않으니 바로 복사**해서
시크릿으로 등록:

| 이름 | 값 |
|---|---|
| `VAPID_PUBLIC_KEY` | 화면의 값 |
| `VAPID_PRIVATE_KEY` | 화면의 값 |
| `VAPID_SUBJECT` | `mailto:ceo@nationalgym.kr` (선택, 연락처) |

> ⚠️ 키를 나중에 바꾸면 기존 폰 구독이 전부 무효가 됩니다(다시 켜야 함). 한 번 정하면 그대로 두세요.

## 5. 크론(자동 실행) 걸기

**Settings → Triggers → Cron Triggers → Add Cron Trigger**

```
0 1,5,10 * * *
```

UTC 기준 01·05·10시 = **한국 시간 10시·14시·19시**. 시간을 바꾸려면 "한국 시간 − 9" 로 적으세요.
매시간(`0 * * * *`)으로 걸어도 워커가 한국 시간 09~21시 밖에는 보내지 않습니다.

## 6. 확인

1. 브라우저로 `https://golf-pt-push.ceo-fc9.workers.dev/health` →
   `{"ok":true,"worker":"golf-pt-push","appKey":true,"db":true,"vapid":true,"subject":true}` 모두 true 여야 합니다.
2. **폰에서** 앱을 열고(프로·트레이너·관리자 계정) 대시보드의 **[🔔 검토 알림을 폰으로 받기]** → 알림 허용.
   - 아이폰: **홈 화면에 추가한 앱**에서만 가능합니다 (사파리 탭에서는 버튼 대신 안내가 뜸). iOS 16.4 이상.
   - 안드로이드(크롬·삼성 인터넷): 그냥 됩니다.
3. 켜지면 같은 자리에 "🔔 폰 알림 켜짐 · **테스트 보내기**" 가 보입니다 → 탭 → 몇 초 안에 폰 알림이 오면 끝.
4. 즉시 독촉 1회 실행해 보려면 (브라우저):
   `https://golf-pt-push.ceo-fc9.workers.dev/push/run?key=APP_API_KEY`
   → `{"pending":N,"subscriptions":M,"sent":[...]}` 에서 `status` 가 201 이면 발송 성공.
   `sent` 가 비어 있으면 검토 대기가 없거나 해당 담당자 구독이 없는 것입니다.
   - 한국 시간 09~21시 밖에는 `skipped:true` 로 건너뜁니다. 밤에 확인하려면 주소 끝에 `&force=1`.
   - 같은 폰에 3시간 안에 이미 보냈으면 `note: "…분 전 발송 → 건너뜀"` 으로 표시되고 다시 보내지 않습니다(크론과 수동 실행이 겹쳐도 폰이 두 번 울리지 않게).

## 동작 규칙

- 검토 대기 = `members.data.reportDirty` 가 있고 `reportId`(회원 링크)가 있는 회원. 관찰용 회원은 제외.
- 프로·트레이너: **본인 담당(assignedTo)** 회원만. 관리자: 전체를 담당자별로 집계.
- 검토 대기가 0 이면 아무 알림도 보내지 않습니다.
- 3일 이상 방치되면 문구에 "⚠️ N일째 회원이 옛 리포트를 보고 있어요" 가 붙습니다.
- 같은 종류 알림은 폰에서 하나로 덮어써져 쌓이지 않습니다.
- 폰이 구독을 지우면(앱 삭제·알림 끔) 푸시 서비스가 404/410 을 돌려주고 워커가 그 구독을 자동 정리합니다.
- 같은 폰에서 다른 사람이 로그인하면 로그인 때 구독이 그 사람으로 다시 묶입니다. 인포데스크로 로그인하면(공용 기기) 남아 있던 다른 사람의 구독을 해제합니다.
- 같은 구독에는 3시간 안에 다시 보내지 않습니다. 테스트 알림은 사용자당 1분에 1회.
- 구독 등록은 검증을 거칩니다: 이름은 회원 담당자로 등록된 이름 또는 '관리자'만, 역할은 이름으로 정해지고(관리자만 admin), 주소는 실제 푸시 서비스(구글·애플·모질라·삼성·MS)만. 사용자당 구독은 5개까지(오래된 것부터 정리).
- 워커의 VAPID 키를 바꾸면 앱이 다음 로그인·버튼 탭 때 옛 구독을 버리고 새 키로 다시 구독합니다.

## 문제 시

- `/health` 에 `vapid:false` → 4번 시크릿 누락. `db:false` → 3번 누락.
- 버튼을 눌렀는데 "알림 서버가 아직 준비되지 않았어요" → 워커 주소가 config.js 와 다르거나 `/push/key` 가 빈 값(시크릿 누락).
- 테스트 알림이 안 옴 → `/push/run?key=…` 결과의 `sent[].status`·`note` 를 확인. 401/403 이면 VAPID 키 문제,
  아이폰이면 홈 화면 앱인지·iOS 16.4 이상인지 확인.
- 워커 로그: Cloudflare → 해당 워커 → **Logs** (크론 실행마다 `reminders {...}` 한 줄).

## 참고

- 이 워커 코드에는 비밀키가 없습니다(시크릿에만). 저장소에 그대로 두어도 안전합니다.
- 발송량: 담당자 3~4명 × 하루 3회 이하 → 무료 플랜으로 충분합니다.
- 관련 파일: `worker/golf-pt-push-worker.js`, `sw.js`(알림 표시), `js/app_dashboard.js`(독촉 창·구독), `config.js`(`PUSH_WORKER_URL`).
