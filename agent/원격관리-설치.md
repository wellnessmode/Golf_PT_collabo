# 타석 PC 원격 유지보수 설치 안내 (headless — 화면 공유 없음)

회원이 트랙맨을 쓰는 중에도, 관리자가 밖에서 **화면을 보지 않고** 점검·로그 수집·에이전트 복구를 할 수 있게 하는 설정입니다.
이 방식은 대화형 데스크톱에 창을 띄우지 않습니다. 숨기는 게 아니라, 백그라운드 명령이라 원래 화면에 안 나타납니다.

## 두 가지를 나눠 봅니다

| | 용도 | 회원 화면 |
|---|---|---|
| **원격 유지보수(이 문서)** | 상태 확인, 로그, 에이전트 재시작, 진단, 업데이트 | 아무것도 안 뜸 (화면 안 봄) |
| **원격 제어(RustDesk)** | 실제 화면을 봐야 할 때만 | 접속 표시가 정상적으로 뜸 (그대로 둠) |

데이터 수집 자체는 타석 PC의 에이전트가 백그라운드에서 합니다. 그건 원래 창도 아이콘도 없습니다.
이 원격 유지보수는 그 에이전트를 밖에서 들여다보고 고치기 위한 것이지, 회원 화면을 보기 위한 것이 아닙니다.

## 구성

1. **Tailscale** — 포트 개방 없이 사설 메시 VPN 으로 PC에 도달. 대표님 계정으로 1회 로그인.
2. **Windows OpenSSH 서버** — 백그라운드 명령 전용. **키 인증만**(비밀번호 로그인 차단), **Tailscale 망에서만** 접속 허용(공개 인터넷에 안 열림).
3. **gpt-admin.ps1** — SSH 로 실행하는 관리 명령.
4. **상태 점검 스케줄** — 30분마다 에이전트가 살아 있는지 보고, 멈췄으면 관리자에게 푸시(관리자 푸시 구독 + config 설정 필요).

## 준비: 관리 PC에서 SSH 키 만들기 (한 번만)

관리에 쓸 노트북/PC에서 한 번만:

```
ssh-keygen -t ed25519
```

- 엔터로 기본 위치에 저장. 생성된 **공개키**(`C:\Users\<나>\.ssh\id_ed25519.pub` 또는 `~/.ssh/id_ed25519.pub`) 내용을 복사해 둡니다. `ssh-ed25519 AAAA... 이름` 한 줄입니다.
- 폰에서만 관리한다면 Termius 같은 SSH 앱에서 키를 만들고 그 공개키를 씁니다.

## 설치 (타석 PC마다, 처음 한 번은 PC 앞에서, 관리자 권한)

PowerShell 을 열고:

```
iwr https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/remote-admin-setup.ps1 -OutFile "$env:TEMP\remote-admin-setup.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\remote-admin-setup.ps1"
```

1. UAC 뜨면 [예].
2. **공개키 붙여넣기**를 물으면 위에서 복사한 공개키 한 줄을 붙여넣습니다.
3. **Tailscale 로그인** 창(브라우저)이 뜨면 대표님 계정으로 로그인합니다. 이 PC가 메시에 등록됩니다.
4. 끝에 이 PC의 **Tailscale IP**(예: 100.x.x.x)와 SSH 접속 예시가 나옵니다. 적어 두세요.

타석마다 반복합니다. Tailscale IP 는 PC마다 다릅니다.

## 사용 (관리 PC/폰에서)

먼저 관리 기기에도 Tailscale 를 깔고 같은 계정으로 로그인합니다. 그다음:

```
ssh <사용자>@<타석PC-Tailscale-IP>
```

또는 명령 하나만 바로:

```
ssh <사용자>@<IP> "powershell -NoProfile -File C:\golfpt-sync\gpt-admin.ps1 status"
```

**명령 목록**

| 명령 | 하는 일 |
|---|---|
| `status` | 에이전트 실행 여부, 베이, 마지막 로그 시각, 디스크 |
| `logs -Tail 40` | agent.log / node-crash.log 최근 줄 |
| `restart` | 에이전트 재시작(데이터 수집 복구) |
| `start` / `stop` | 켜기 / 끄기 |
| `diag` | 데이터 수집 확인 — 최근 24시간 트랙맨 샷 파일 수·최신 시각, 에이전트 업로드 건수 |
| `update` | 에이전트 최신본으로 교체 후 재시작 |
| `health` | 살아 있으면 0, 멈췄으면 1 (스케줄이 사용) |

> `diag` 는 파일만 읽어 "데이터가 실제로 쌓이는지"를 확인합니다. 화면을 캡처하지 않습니다.
> "20:00 ~ 김*아" 같은 예약 화면을 읽는 진단은 화면이 필요해 SSH 로는 안 됩니다. 그건 PC 앞에서 `player-diag.ps1` 로 직접 실행하세요(원격 SSH 세션은 회원 데스크톱 화면에 접근하지 않습니다).

**로그·결과 파일 내려받기**는 scp 로:

```
scp <사용자>@<IP>:C:/golfpt-sync/agent.log .
scp <사용자>@<IP>:C:/golfpt-sync/diag/*.txt .
```

## 멈췄을 때 알림 받기 (선택)

`C:\golfpt-sync\config.json` 에 아래를 추가하면, 상태 점검 스케줄이 에이전트 중단을 감지해 관리자에게 푸시를 보냅니다.

```
"PUSH_WORKER_URL": "https://golf-pt-push.<대표님>.workers.dev",
"adminNames": ["관리자"]
```

`R2_API_KEY` 는 이미 있는 값을 그대로 씁니다. 관리자 이름(`관리자`)으로 폰 푸시 구독이 돼 있어야 알림이 도착합니다.

## 안전

- SSH 는 **키 인증만**, 비밀번호 로그인은 차단됩니다. 공개키를 등록한 기기에서만 들어옵니다.
- SSH 는 **Tailscale 망에서만** 접속됩니다. 공개 인터넷에는 열리지 않습니다.
- 접속·명령은 윈도우 이벤트 로그와 sshd 로그에 남습니다.
- 이 방식은 **화면을 보지 않습니다.** 회원 트랙맨 화면·입력 포커스·해상도·실행 상태에 영향을 주지 않고, 새 창도 안 뜹니다.
- 회원 화면을 실제로 봐야 하는 작업은 이 범위에 없습니다. 그때는 RustDesk 로 접속하고, 그 접속 표시는 그대로 둡니다(회원이 원격 접속을 알 수 있어야 하므로).

## 안 될 때

- `ssh` 가 연결 안 됨: 관리 기기와 타석 PC 둘 다 Tailscale 에 로그인돼 있는지, `tailscale status` 에 그 PC가 보이는지 확인.
- 키를 물어보지 않고 비밀번호를 물으면: 공개키 등록이 안 된 것. `C:\ProgramData\ssh\administrators_authorized_keys` 에 공개키가 있고 ACL 이 Administrators/SYSTEM 전용인지 확인.
- 구형 윈도우10에서 OpenSSH 서버가 없으면: 설정 → 앱 → 선택적 기능 → "OpenSSH 서버" 추가 후 스크립트 재실행.
