# 원격 화면 제어 — 연결 창이 트랙맨을 안 가리는 방식 (VNC + Tailscale)

폰·노트북에서 매장 PC 화면을 실시간으로 보고 조작하되, 접속 중 뜨는 **커다란 연결 상태 창으로 트랙맨 화면을 가리지 않게** 하는 방식입니다.
기존 RustDesk 는 그대로 두고(원할 때 씀), 이 방식을 추가로 설치합니다.

## 왜 VNC 인가 — 대안 비교

| 방식 | 접속 중 화면에 뜨는 것 | 트랙맨 유지 | 폰 제어 | 재부팅 | 판정 |
|---|---|---|---|---|---|
| **RustDesk** | **커다란 연결 상태 창**(자동 최소화·이동 공식 설정 없음) | O | O | O(서비스) | 창이 화면을 가림 — 이 문제의 원인 |
| **Chrome 원격 데스크톱** | 이동만 되는 공유 알림 막대 + 사전승인 접속은 주기적으로 "계속 공유" 확인을 요구(끊김) | O | O | O | 막대가 남고 주기적 중단 위험 — 부적합 |
| **Windows 원격데스크톱(RDP)** | — | **X (로컬 세션이 잠김)** | △ | O | 회원 화면이 꺼짐 — 부적합 |
| **VNC(TightVNC) + Tailscale** | **없음**(큰 창 없음). 접속 중에만 **작은 구석 표시** | O(미러링) | O | O(서비스) | **채택** |

VNC 는 콘솔 화면을 **그대로 미러링**합니다. 접속해도 큰 창이 안 뜨고, 트랙맨 전체화면·해상도·입력이 그대로입니다.
"원격 접속 중" 표시는 큰 창 대신 **화면 구석의 작은 알약**(이 프로젝트의 `vnc-indicator.ps1`)으로 띄웁니다. 비차단형이고, 클릭하면 연결이 끊깁니다.

## 설치 (타석 PC마다, 처음 한 번은 PC 앞에서, 관리자 권한)

```
iwr https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/remote-vnc-setup.ps1 -OutFile "$env:TEMP\remote-vnc-setup.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\remote-vnc-setup.ps1" -Branch "3호점 1번타석"
```

1. UAC [예]. **VNC 암호**를 정합니다(VNC 규격상 앞 8자만 쓰입니다). 접속은 Tailscale 망에서만 되므로 암호는 2차 방어입니다.
2. **Tailscale 로그인** 창에서 대표님 계정으로 로그인(이 PC를 메시에 등록).
3. 끝에 이 PC의 **Tailscale IP**(100.x.x.x)와 포트 5900 이 나옵니다.
4. 설치 내용: TightVNC 서버(서비스), VNC 5900 을 **Tailscale 망에서만** 허용(공개 인터넷 미개방), 접속 중 구석 표시 자동 실행.

## 접속 (폰·노트북)

관리 기기에도 Tailscale 를 깔고 같은 계정으로 로그인합니다. 그다음:

- **아이폰/안드로이드**: "RealVNC Viewer" 앱(또는 안드로이드 "bVNC") 설치 → 주소 `<Tailscale IP>:5900` → VNC 암호 → 매장 화면이 뜨고 마우스·키보드 조작.
- **노트북/PC**: 아무 VNC 뷰어(RealVNC Viewer 등)에서 같은 주소·암호.

## 접속 중 표시 (비차단) + 연결 종료

- 접속해 있는 동안에만 매장 PC 화면 **우측 상단 구석**에 작은 빨간 알약 **"● 원격 접속 중"** 이 뜹니다. 중앙 트랙맨 화면을 가리지 않습니다. 접속이 없으면 사라집니다.
- 그 알약을 **클릭 → "연결 끊기"** 하면 끊어집니다. 권한이 없어 바로 안 되면, 안내대로 **작업표시줄 TightVNC 아이콘 우클릭 → Disconnect all clients** 또는 **Tailscale 에서 이 기기 내리기**로 끊습니다.
- 접속 사실 표시와 종료 기능은 유지됩니다(무력화하지 않음).

## 검증 체크리스트 (여기까지 되면 합격)

1. 폰 VNC 뷰어에서 `<Tailscale IP>:5900` + 암호로 **매장 화면이 뜬다**.
2. 폰에서 마우스·키보드로 **조작된다**.
3. 접속하는 순간 **큰 연결 창이 안 뜬다**. 트랙맨 전체화면·해상도·입력 **그대로**.
4. 접속 중 화면 구석에 **작은 "● 원격 접속 중"** 만 뜬다(중앙 안 가림).
5. 그 표시 **클릭 → 연결 끊기**가 된다.
6. 매장 PC **재부팅 후**에도 사람 없이 1~2가 된다.

> 3~6번은 실제 기기·타석에서만 확인됩니다. 특히 **전체화면 독점(Exclusive Fullscreen) 앱 위에는 구석 표시가 안 보일 수 있으니**, 트랙맨을 띄운 상태에서 표시가 보이는지 확인해 주세요. 안 보이면 알려주시면 표시 방식을 조정합니다.

## 보안

- VNC(5900)는 **Tailscale 망에서만** 접속됩니다. 공개 인터넷에 안 열립니다.
- VNC 암호는 앞 8자만 유효(규격)라 약하지만, Tailscale(WireGuard)로 **종단간 암호화된 터널** 안에서만 쓰여 감싸집니다. Tailscale 계정 인증이 1차, VNC 암호가 2차입니다.
- 접속 사실 표시(구석 알약)와 종료 기능은 유지합니다.

## 기존과의 관계 (충돌 없음)

- **RustDesk**(기존): 그대로 둡니다. 화면 제어가 필요하고 연결 창이 상관없는 경우 계속 쓸 수 있습니다.
- **SSH 관리도구**(PR #132): 화면 없는 백그라운드 점검·데이터 수집용. 이 VNC 와 별개.
- **golfpt-sync 에이전트**(샷 수집): node 백그라운드. 포트·서비스·작업이 모두 달라 충돌하지 않습니다.
- 3호점·서초점 모두 같은 명령으로 설치합니다(`-Branch` 로 구분).

## 안 될 때

- 접속이 안 됨: 관리 기기와 매장 PC 둘 다 Tailscale 로그인 상태인지, `tailscale status` 에 그 PC가 보이는지 확인.
- 화면은 뜨는데 조작이 안 됨: VNC 뷰어가 "보기 전용"이 아닌지 확인.
- TightVNC 설치가 안 됨: https://www.tightvnc.com/download.php 에서 설치 후 스크립트 재실행(`-VncMsiUrl` 로 다른 버전 지정 가능).
