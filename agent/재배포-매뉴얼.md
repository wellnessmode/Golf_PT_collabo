# 스튜디오 에이전트 재배포 — agent.js + ftmf-parser.js 교체 (약 5분)

이미 설치돼 돌고 있는 에이전트(`C:\golfpt-sync`)에서 **`agent.js` 와 `ftmf-parser.js` 두 파일**을 최신본으로 교체합니다.

> ⚠️ **두 파일 다** 바꿔야 합니다. `agent.js` 가 `ftmf-parser.js` 를 불러 쓰기 때문에, 한쪽만 바꾸면 클럽 인식·영상 매칭이 안 맞습니다.

이번 업데이트에 담긴 것:
- **타석 레슨 게이트** — 앱에서 "타석 레슨"을 켠 베이의 샷만 저장(연습 샷은 저장 안 함)
- **영상 측면·정면 매칭** — Videos 폴더의 아이폰 DL(측면)·FO(정면) 영상을 샷에 자동 첨부
- **클럽 오인식 수정** — 레이더 추측 대신 TPS에서 선택한 클럽을 사용
- **단독 stmf 정리** — 트랙맨 상태와 무관하게 timed_out 측정도 샷당 1개로 병합·최선값 채택

> config.json·다른 파일은 그대로 둡니다. 트랙맨(TPS)은 안 건드립니다.

## ⭐ 방법 0. 올인원 (앞으로 이것만) — 붙여넣기 한 번이면 끝

**시작 메뉴 → "PowerShell"** 실행 후 아래 두 줄을 통째로 붙여넣고 Enter.
중지 → 최신 다운로드 → 검증(깨진 파일 차단) → 재시작 → 실행 확인 → 오류 로그 출력까지 전부 자동입니다.

```powershell
iwr https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/update.ps1 -OutFile "$env:TEMP\gpt-update.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\gpt-update.ps1"
```

- 끝에 **[성공] 에이전트 실행 중** 이 초록색으로 뜨면 완료.
- **[실패]** 가 뜨면 함께 출력되는 `node-crash.log` 부분을 사진 찍어 공유해 주세요 — 시작 실패의 정확한 사유가 거기 찍힙니다.
- 중지.bat / 설치_자동시작.bat 을 따로 누를 필요가 없습니다.

## 방법 A. PowerShell 수동 (참고용)

1. `C:\golfpt-sync` 폴더에서 **중지.bat** 더블클릭 → **상태확인.bat** 으로 `상태 : [ 중지됨 ]` 확인.
2. **시작 메뉴 → "PowerShell"** 검색 → **Windows PowerShell** 실행.
3. 아래 블록을 통째로 복사해 붙여넣고 Enter (기존 파일은 `_old` 로 백업됨):

```powershell
cd C:\golfpt-sync
copy agent.js agent_old.js -Force
copy ftmf-parser.js ftmf-parser_old.js -Force
$b='https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent'
Invoke-WebRequest "$b/agent.js"        -OutFile agent.js
Invoke-WebRequest "$b/ftmf-parser.js"  -OutFile ftmf-parser.js
Write-Host "교체 완료 — agent.js / ftmf-parser.js 최신본"
```

4. `C:\golfpt-sync` 에서 **설치_자동시작.bat** 더블클릭 (파란 보호창 → 추가 정보 → 실행).

## 방법 B. 브라우저로 받기 (PowerShell 안 쓸 때)

1. **중지.bat** → **상태확인.bat** 으로 중지 확인.
2. 브라우저 주소창에 각각 붙여넣어 이동 → 코드가 뜨면 **Ctrl+S**:
   - `https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/agent.js`
   - `https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/ftmf-parser.js`
   - ⚠️ 저장 시 파일명이 정확히 `agent.js` / `ftmf-parser.js` 인지 확인(`.txt` 붙지 않게).
3. 기존 `C:\golfpt-sync\agent.js` → `agent_old.js`, `ftmf-parser.js` → `ftmf-parser_old.js` 로 이름 바꿔 백업.
4. 받은 두 파일을 `C:\golfpt-sync` 로 복사.
5. **설치_자동시작.bat** 실행.

> 대안: `github.com/wellnessmode/Golf_PT_collabo` → `<> Code` → Download ZIP → 압축 풀고 `agent` 폴더의 두 파일 사용.

## 확인 (중요)

**상태확인.bat** 더블클릭 후 로그에서 확인:

1. `=== Golf PT Bay Agent 시작 ===` 이 **방금 시각**으로 새로 찍혔는지
2. **`타석 레슨 게이트: ON`** 줄이 보이는지 ← ⭐ 이게 보이면 새 버전이 맞습니다
3. `autoAddTmfsWatch` 마커 감지 문구(상태확인.bat 상단)가 `최신` 으로 뜨는지
4. `✓ PC 시계 정확` 인지 (아니면 시계 동기화 후 중지→설치_자동시작)

**실전 확인:** 앱에서 **타석 3번 → 회원 배정 → 타석 레슨 시작** 한 뒤 공 1개 치면, 몇 초 안에 앱 최근 샷에 뜨고 잠시 후 영상 [측면]/[정면] 이 붙습니다. 레슨을 **안 켜고** 친 연습 샷은 저장되지 않아야 정상입니다.
