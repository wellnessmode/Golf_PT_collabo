# 스튜디오 에이전트 재배포 — agent.js 교체 (약 5분)

이미 설치돼 돌고 있는 에이전트(`C:\golfpt-sync`)에서 **`agent.js` 한 파일만 최신본으로 교체**하면 됩니다.
이번 업데이트: mp4 변환본이 만들어지면 **용량 2배인 mkv 원본을 자동 삭제** → 신규 스윙 저장량 약 절반.

> config.json·다른 파일은 그대로 둡니다. 트랙맨(TPS)은 안 건드립니다.

---

## 1단계. 최신 agent.js 내려받기

브라우저(엣지/크롬) 주소창에 아래를 붙여넣고 이동:

```
https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/agent.js
```

- 코드 텍스트가 화면에 뜨면 → **Ctrl + S** → 저장 위치는 **다운로드** 폴더, 파일 이름 `agent.js` 확인 → 저장.
- (파일 형식이 "텍스트"로 저장되면서 `agent.js.txt`가 되지 않게, 이름이 정확히 `agent.js`인지 확인)

> 안 되면 대안: `github.com/wellnessmode/Golf_PT_collabo` → **`<> Code` → Download ZIP** → 압축 풀고 `agent` 폴더 안의 `agent.js` 사용.

---

## 2단계. 에이전트 멈추기

1. `C:\golfpt-sync` 폴더 열기
2. **중지.bat** 더블클릭 → 잠시 후 백그라운드 node가 종료됩니다.
3. (확인) **상태확인.bat** 더블클릭 → `상태 : [ 중지됨 ]` 이면 OK. 창 닫기.

> bat이 안 먹으면: **Ctrl+Shift+Esc**(작업 관리자) → 프로세스에서 **Node.js JavaScript Runtime** 과 **Windows Based Script Host(wscript)** 를 각각 → **작업 끝내기**.

---

## 3단계. agent.js 교체 (기존 것 백업)

1. `C:\golfpt-sync` 폴더에서 기존 **agent.js** → 우클릭 → **이름 바꾸기** → `agent_old.js` (혹시 몰라 백업)
2. 1단계에서 받은 새 **agent.js** 를 `C:\golfpt-sync` 로 **복사(Ctrl+C → Ctrl+V)**
3. 폴더에 `agent.js`(새것) + `agent_old.js`(백업) 둘 다 있으면 OK

---

## 4단계. 다시 켜기

1. **설치_자동시작.bat** 더블클릭 (파란 보호창 뜨면 → 추가 정보 → 실행)
2. `[실행됨] 에이전트가 백그라운드에서 동작 중입니다.` 확인 → 아무 키 → 창 닫기

---

## 5단계. 동작·업데이트 확인 (중요)

**상태확인.bat** 더블클릭 후 로그에서 아래 3가지 확인:

1. `=== Golf PT Bay Agent 시작 ===` 이 **방금 시각**으로 새로 찍혔는지
2. **`영상 변환(MP4): ON → …`** 인지 **`OFF (ffmpegPath 미설정)`** 인지 ← ⭐ **이 줄을 사진 찍어 저에게 보내주세요**
   - **ON** 이면: mkv+mp4 이중 저장이 실제로 일어나고 있었던 것 → 이번 수정으로 앞으로 절반. 앱의 🧹 스토리지 진단에서 "중복 mkv" 정리로 과거분 수백 GB 회수 가능.
   - **OFF** 이면: 이 스튜디오는 mkv만 저장 중 → 이중 저장은 없음(회수할 중복 mkv 없음). 이 경우 비용 절감은 라이프사이클·연습샷 정리 쪽으로 갑니다.
3. `✓ PC 시계 정확` 인지 (아니면 시계 동기화 후 중지.bat→설치_자동시작.bat)

**실전 확인(선택):** MP4가 ON이면, 트랙맨으로 공 1개 친 뒤 `agent.log`(C:\golfpt-sync 안) 끝부분에
`원본 mkv 삭제(저장비 절감) …` 줄이 뜨면 새 버전이 정상 동작하는 것입니다.

---

## 문제 시 되돌리기 (롤백)

중지.bat → `agent.js` 삭제 → `agent_old.js` 를 `agent.js` 로 이름 되돌리기 → 설치_자동시작.bat.

문제 생기면 `agent.log` 마지막 부분 + 5단계 2번 줄 사진 찍어 공유해 주세요.
