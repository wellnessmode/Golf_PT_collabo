# 1번·2번 타석 PC 에이전트 설치 — 3번룸과 똑같이 만들기

> 타석 PC 1대당 약 10분. 두 PC 모두 같은 절차 (defaultBay 값만 다름).
> 트랙맨 프로그램(TPS)은 안 건드립니다.

---

## 0단계. 준비물

- 각 타석 PC 인터넷 연결
- **USB 메모리 1개** — 3번룸 PC의 ffmpeg 폴더를 복사해 갈 것

---

## 1단계. PC 시계 맞추기

3번룸 매뉴얼 2단계와 동일:
설정 → 날짜 및 시간 → **자동으로 설정 켬** → **지금 동기화** → 폰 시계와 분 단위까지 일치 확인.

---

## 2단계. Node.js 설치

1. **Win + R** → `cmd` → `node -v`
   - `v20.x.x` 처럼 나오면 → 3단계로
   - 안 나오면 → `nodejs.org` 접속 → 초록 **LTS** 버튼 → 받은 파일 실행 → 전부 Next
2. 설치 후 검은 창 새로 열어 `node -v` 로 재확인

---

## 3단계. ffmpeg 복사 (영상 변환용)

1. **3번룸 PC**에서 `C:\golfpt-sync\config.json` 을 메모장으로 열고
   `"ffmpegPath"` 값 확인 (예: `"C:\\ffmpeg\\bin\\ffmpeg.exe"`)
2. 그 경로의 **ffmpeg 폴더 전체**(예: `C:\ffmpeg`)를 USB에 복사
3. **새 타석 PC**의 같은 위치(예: `C:\` 바로 아래)에 붙여넣기

> ffmpeg 없이도 측정 수치는 다 들어오지만, 영상이 아이폰에서 재생 안 되는 형식으로
> 올라갈 수 있어 반드시 넣는 걸 권장.

---

## 4단계. 에이전트 설치 — 파워셸 두 줄 (신규 설치 모드)

1. **시작 버튼 우클릭 → Windows PowerShell** (또는 "터미널")
2. 아래 두 줄 붙여넣기 + 엔터:
   ```powershell
   iwr https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/update.ps1 -OutFile "$env:TEMP\gpt-update.ps1"
   powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\gpt-update.ps1"
   ```
3. `[신규 설치 모드]` 라고 뜨며 파일을 받고, **메모장이 자동으로 열립니다**

---

## 5단계. 메모장에서 딱 3곳 수정 (열린 config.json)

| 항목 | 바꾸기 전 | 바꾼 후 |
|---|---|---|
| `defaultBay` | `"bay3"` | **1번타석 PC는 `"bay1"` · 2번타석 PC는 `"bay2"`** |
| `bayMap` | `{ "24240089": "bay3" }` | `{}` |
| `ffmpegPath` | `""` | 3단계에서 확인한 값 (예: `"C:\\ffmpeg\\bin\\ffmpeg.exe"`) |

- 역슬래시는 꼭 **두 개씩**(`\\`) 입니다
- **Ctrl + S** 로 저장 → 메모장 닫기

---

## 6단계. 두 줄 다시 실행 → 시작

4단계의 두 줄을 **한 번 더** 실행.
이번엔 끝까지 진행되며 아래가 나오면 성공:

```
[성공] 에이전트 실행 중 (PID xxxx)
[자동시작] 등록됨 - PC 를 껐다 켜도 자동 실행됩니다.
```

하단 agent.log 에 `=== Golf PT Bay Agent 시작 ===` 과 `✓ PC 시계 정확` 확인.

---

## 7단계. 실전 테스트 (휴대폰)

1. 폰 앱 새로고침 → **🏌️ 수업 센터**
2. **🎯 라이브 수업** → 회원 선택 → **1번타석**(또는 2번타석) 선택
3. 그 타석 트랙맨에서 공 1개 치기
4. 5~10초 안에 폰 베이 카드에 샷이 뜨면 🎉 완성
5. (선택) `C:\golfpt-sync\agent.log` 에 찍힌 트랙맨 시리얼을
   config.json `bayMap` 에 `{ "시리얼": "bay1" }` 로 넣어두면 더 단단해짐

---

## 8단계. 재부팅 테스트

PC 다시 시작 → 아무것도 안 하고 1~2분 뒤 폰에서 샷 수신되는지 (또는
4단계 두 줄 실행 시 상단에 `[성공] 에이전트 실행 중` 뜨는지) 확인.

---

## 영상 관련 참고

- 측면/정면 영상은 **그 타석에 아이폰 카메라가 TPS에 연결돼 있어야** 붙습니다.
  카메라 없는 타석은 측정 수치만 들어옵니다 (정상).
- 아이폰 카메라는 **"비디오" 모드**로 두세요 — "슬로 모션" 모드면 영상이 늘어져
  올라옵니다 (에이전트가 자동 보정하긴 하지만 원본이 정상인 게 최선).

---

## 문제 생겼을 때

| 증상 | 해결 |
|---|---|
| `[오류] Node.js 가 설치되어 있지 않습니다` | 2단계 다시 |
| 메모장이 안 열림 / config 수정 놓침 | `C:\golfpt-sync\config.json` 직접 열어 5단계 수정 |
| 공 쳤는데 폰에 안 뜸 | ① 앱에서 그 타석으로 라이브 수업 시작했는지 ② 두 줄 재실행해 [성공] 확인 ③ agent.log 끝부분 확인 |
| 샷이 3번룸으로 들어감 | config.json 의 defaultBay 가 bay3 로 남은 것 — 5단계 수정 후 두 줄 재실행 |
| 시계 어긋남 경고 | 1단계 다시 → 두 줄 재실행 |

문제 시 **agent.log** 마지막 부분을 사진 찍어 공유.
