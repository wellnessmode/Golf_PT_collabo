# PC 원격접속 설치 안내 (RustDesk) — 타석 PC·업무용 PC 공용

대표님이 필요할 때 폰이나 노트북에서 이 PC에 접속해 작업하기 위한 설정입니다.
PC가 항상 켜져 있으면, 한 번 설정해 두고 무인(사람이 PC 앞에 없어도) 접속됩니다.

> **역할 구분**: 실제 화면을 보고 마우스·키보드로 조작해야 하는 일은 **RustDesk**(이 문서)로 합니다.
> 화면 없이 백그라운드로 하는 상태 확인·로그 수집·에이전트 재시작·데이터 수집 점검은 **SSH 관리 도구**(`원격관리-설치.md`, `gpt-admin.ps1`)로 하면 회원 화면에 아무것도 안 뜹니다. 둘을 같이 써도 됩니다.

같은 스크립트가 **타석 PC(트랙맨 있음)** 와 **업무용 PC(트랙맨 없음, 예: 서초점)** 둘 다에서 동작합니다.
- 타석 PC: 원격접속 + 조용한 진단 스크립트(`player-diag.ps1`)까지 같이 받아 둡니다.
- 업무용 PC: 원격접속만 세팅합니다. 진단 스크립트나 `C:\golfpt-sync` 폴더를 만들지 않고, 접속정보는 바탕화면 `RustDesk-접속정보.txt` 에 적습니다. 끝에 "절전(잠자기)에 들어가면 밖에서 접속이 끊긴다"는 안내가 나오니, 윈도우 설정에서 절전을 꺼 두세요(스크립트가 전원 설정을 바꾸지는 않습니다).

## 왜 RustDesk 인가
- 오픈소스·무료이고 **상업적 사용도 허용**됩니다 (팀뷰어는 매장 PC를 "상업용"으로 보고 무료 접속을 자주 막습니다).
- **계정 가입이 필요 없습니다.** 접속 ID(숫자 9~10자리) + 비밀번호만 있으면 됩니다.
- 설치부터 비밀번호 설정까지 한 번의 명령으로 끝납니다.
- 연결은 종단간 암호화됩니다. 더 엄격히 하려면 나중에 중계 서버를 직접 운영할 수도 있습니다(선택).

> 다른 도구가 편하시면 말씀해 주세요. **AnyDesk**(쉬움, 상업용은 유료 라이선스 권장), **Chrome 원격 데스크톱**(구글 계정 로그인 필요, 설치가 자동화는 안 되고 브라우저에서 수동 설정)으로도 가능합니다.

## 설치 (PC마다 한 번, 처음은 PC 앞에서)

설치에는 관리자 권한이 필요해서 **처음 한 번은 타석 PC 앞에서** 해야 합니다. 이후부터는 원격으로 접속됩니다.

1. 타석 PC에서 PowerShell 을 엽니다. (시작 메뉴 → "PowerShell" 입력)
2. 아래 두 줄을 붙여넣고 실행합니다.

   ```
   iwr https://raw.githubusercontent.com/wellnessmode/Golf_PT_collabo/main/agent/remote-setup.ps1 -OutFile "$env:TEMP\remote-setup.ps1"
   powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\remote-setup.ps1"
   ```

3. 관리자 권한 창(UAC)이 뜨면 **[예]** 를 누릅니다.
4. **접속 비밀번호**를 정해 입력합니다 (영문+숫자 8자 이상 권장). 화면엔 안 보이게 입력되고, 두 번 입력해 확인합니다.
   - 이 비밀번호는 **어디에도 저장되지 않습니다.** 대표님만 기억하세요.
5. 설치가 끝나면 **이 PC의 RustDesk ID**(숫자 9~10자리)가 화면에 나옵니다. ID 는 `C:\golfpt-sync\diag\remote-id.txt` 에도 적어 둡니다 (비밀번호는 저장 안 함).
6. 타석이 3개면 **각 PC에서 1~5번을 반복**합니다. PC마다 ID 가 다릅니다. 비밀번호는 같게 해도 되고 다르게 해도 됩니다.

## 접속 (어디서든)

> **먼저 접속하는 쪽(폰·노트북) 앱에서 로그인하세요.** RustDesk 무료 공용 서버가 악용 방지 때문에 접속하는 사람의 로그인을 요구합니다. 무료이고 구글 계정으로 됩니다. 로그인 없이 접속하면 "WebRTC failed: The connection is not allowed ... requires users to log in" 오류가 납니다. 타석·업무용 PC 쪽은 로그인할 필요 없습니다.
> 폰 앱: 설정 → 맨 위 "로그인" → 구글로 로그인.

1. 폰이나 노트북에 RustDesk 앱을 설치합니다: https://rustdesk.com (앱스토어·플레이스토어에도 "RustDesk" 있음)
2. 접속할 타석 PC의 **ID** 를 입력하고 연결합니다.
3. 설치 때 정한 **비밀번호**를 넣으면 그 PC 화면이 그대로 보이고 조작할 수 있습니다.

## 폰·노트북에서 실제 화면 보고 조작하기 (아이폰/안드로이드/PC)

실시간 화면 보기 + 마우스·키보드 조작은 **폰·노트북이 "조작하는 쪽"** 이 되어 윈도우 매장 PC에 접속하는 방식입니다.

- **아이폰·아이패드·안드로이드 모두 조작하는 쪽은 됩니다.** 즉 폰에서 매장 PC 화면을 보고 터치로 마우스·키보드를 움직일 수 있습니다.
  - 폰 화면에서 손가락으로 마우스를 움직이는 "마우스 모드"와, 화면을 직접 터치하는 "터치 모드"를 접속 중 전환할 수 있습니다. 키보드는 상단 키보드 버튼으로 띄웁니다.
  - (참고: 아이폰 자체를 "조작당하는 쪽"으로 쓰는 건 애플 제약으로 불가합니다. 매장 PC는 윈도우라 해당 없음.)
- **재부팅 후 무인 접속**: 설치 스크립트가 RustDesk 를 **서비스로** 설치하므로, 매장 PC를 껐다 켜도 로그인 전에 서비스가 떠서 사람 없이 다시 접속됩니다. (단, PC가 꺼져 있거나 절전이면 안 됩니다 — 위 업무용 PC 안내 참고.)

### 검증 체크리스트 (여기까지 되면 완료)

1. 폰 RustDesk 앱에서 **로그인**(구글)이 돼 있다.
2. 매장 PC **ID 입력 → 연결 → 비밀번호 입력**으로 화면이 뜬다.
3. 폰에서 마우스를 움직이면 **PC 커서가 따라 움직인다**(조작됨).
4. 키보드 버튼으로 **글자 입력이 된다**.
5. 접속을 끊었다가 **매장 PC를 재부팅한 뒤**, 사람 없이 다시 2~4가 된다.
6. 접속 시 회원 화면에 **"수락" 창이 안 뜬다**(아래 무인 접속 설정).

> 이 체크리스트의 3~5번은 실제 기기에서만 확인됩니다. 되면 완료이고, 어느 단계에서 막히면 그 화면을 보내주세요.

## 접속할 때 PC 화면에 "수락" 창이 뜰 때 (무인 접속으로 바꾸기)

폰에서 연결했을 때 타석 PC 화면에 "○○○ 님이 장치에 대한 액세스 권한을 요청합니다 — 수락/취소" 창이 뜨면,
그건 **비밀번호 없이 연결해서 "허락해 달라"고 요청**한 것입니다. 연습 중인 회원 화면에 이 창이 뜨면 안 되니, 아래로 바꿉니다.

1. **폰에서 접속할 때 비밀번호를 넣으세요.** 연결 누르면 폰이 비밀번호를 물어봅니다. 거기에 영구 비밀번호를 넣으면 **수락 창 없이 바로** 연결됩니다. 그냥 연결만 기다리면 PC에 수락 창이 뜹니다.
2. **PC를 "비밀번호로만" 접속 허용으로 바꾸세요** (한 번만, PC마다). 그러면 비밀번호로만 접속되고, 수락 창(클릭 승인)은 아예 안 뜹니다.
   - 타석 PC의 RustDesk 창에서 비밀번호 칸 옆 **⋮(점 세 개)** 메뉴를 엽니다.
   - **영구 비밀번호**가 설정돼 있는지 확인하고(없으면 "영구 비밀번호 설정"으로 정함),
   - 접속 승인 방식을 **"비밀번호로만"** (영문 UI 면 approve mode = **password**, "password-click" 이 기본값)으로 바꿉니다.
3. 폰 앱에서 그 PC를 즐겨찾기(이름 붙여 저장)해 두면, 다음부터 목록에서 눌러 비밀번호만 넣고 바로 들어갑니다.

> 참고: RustDesk 는 접속 중일 때 타석 PC 작업표시줄에 접속 표시가 남습니다(정상 동작). 수락 창만 안 뜨게 하는 것이고, 접속 자체를 숨기는 것은 아닙니다.

## 지점별 관리 (3호점·서초점)

PC마다 RustDesk ID 가 다릅니다. 지점·타석을 구분해 두면 폰에서 바로 찾습니다.

- 설치할 때 이름표를 같이 넣을 수 있습니다:
  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\remote-setup.ps1" -Branch "3호점 1번타석"
  ```
  (안 넣으면 설치 중에 물어봅니다. 엔터로 건너뛰어도 됩니다.) 이름표는 접속정보 메모에 같이 적힙니다.
- **폰·노트북 RustDesk 앱 주소록**에 각 PC를 그 이름(예: `3호점 1번타석`, `서초점 업무`)으로 저장해 두세요. 다음부터 목록에서 눌러 바로 들어갑니다.
- 한 곳에 표로 적어 두면 편합니다:

  | 지점 | 타석/용도 | RustDesk ID |
  |---|---|---|
  | 3호점 | 1번타석 | (설치 때 나온 숫자) |
  | 3호점 | 2번타석 |  |
  | 서초점 | 업무 PC |  |

## 회원 방해 줄이기 (정상 설정 범위 — 접속 표시·보안은 유지)

접속 표시와 보안은 그대로 두고, 연습 중인 회원을 방해할 만한 것만 RustDesk 기본 설정에서 줄입니다.
RustDesk 창 → ☰ → 설정 → 보안 → "권한"(또는 접속 중 권한 패널의 아이콘)에서:

- **오디오 끄기** 🔊 — 접속 중 PC 소리를 끌어오지 않게. (회원 쪽 스피커엔 영향 없지만 불필요하니 꺼 둡니다.)
- **재시작 권한 끄기** 🔄 — 원격에서 실수로 PC를 재시작하지 못하게. (연습 중 재부팅 방지.)
- **키보드·마우스·클립보드는 켜 둡니다** — 대표님이 조작해야 하니 유지.
- 접속할 때 **승인 방식은 "비밀번호로만"**(위 무인 접속) — 수락 창이 안 떠서 화면 전환이 없습니다.
- **접속 표시(연결 상태 창)와 보안은 그대로 둡니다.** PC 앞에 있는 사람이 원격 접속을 알 수 있어야 하므로 없애지 않습니다. 거슬리면 그 창의 ─(최소화)로 치워 둘 수 있습니다.

> 이렇게 하면 접속·조작 중에도 회원 트랙맨 화면이 전환되거나 소리가 나거나 재시작되는 일이 없습니다. 접속 표시만 남습니다.

## 연결 상태 창("연결됨 00:00:17")이 트랙맨 화면을 가릴 때

접속 중 뜨는 그 연결 상태 창(연결 관리 창, CM window)을 **"접속 표시는 그대로 두면서 자동으로 최소화하거나 구석으로 옮기는" 공식 설정은 RustDesk 에 없습니다.** (버전 확인은 RustDesk → ☰ → 정보에서.)

- RustDesk 에 있는 유일한 관련 설정은 **"연결 관리 창 숨기기"**(설정 → 보안 → 비밀번호; approve mode=password + 영구 비밀번호 + allow-hide-cm 조건)인데, 이건 창뿐 아니라 **"누가 접속 중"이라는 표시 자체를 전부 없앱니다.** 대표님이 유지하라고 하신 접속 표시가 사라지므로, 이 설정은 **적용하지 않았습니다.**
- 즉 공식 설정만으로는 "표시는 남기고 창만 안 가리게"가 안 됩니다. 아래가 가장 근접한 대안입니다.

### 가장 근접한 대안 (접속 표시는 유지)

1. **모니터 배치 (추천 — "작업 화면 밖에 배치"에 가장 가까움)**
   연결 상태 창은 보통 **윈도우 주 모니터**에 뜹니다. 타석 PC는 모니터·빔까지 화면이 여러 개이니, **회원이 보는 트랙맨 화면을 주 모니터가 아닌 쪽**으로 두면 상태 창이 회원 화면이 아니라 운영용 모니터에 뜹니다.
   - 윈도우 설정 → 시스템 → 디스플레이에서, 운영용(작은) 모니터를 선택하고 "이 디스플레이를 주 디스플레이로 만들기"에 체크. 트랙맨 전체화면은 회원용(빔) 화면에 그대로 둡니다.
   - PC마다 모니터 구성이 달라 스크립트로 자동 변경하지는 않습니다(잘못 바꾸면 트랙맨 화면이 흔들릴 수 있어서). 한 번 직접 맞춰 두시면 됩니다. 맞춘 뒤 실제로 접속해 상태 창이 어느 화면에 뜨는지 확인하세요.

2. **접속할 때 한 번 최소화**
   상태 창 오른쪽 위 **─(최소화)** 를 누르면 작업표시줄로 들어가 화면을 안 가립니다(표시는 작업표시줄에 남음). 다만 접속할 때마다 떠서, 매번 한 번 눌러야 합니다(자동 최소화는 공식 지원 없음).

3. **이미 적용한 방해 줄이기**(위 "회원 방해 줄이기")
   승인=비밀번호로만(수락 창 없음), 오디오·재시작 권한 끄기로 팝업·소리·화면 전환은 이미 없앴습니다. 남는 건 이 연결 상태 창 하나입니다.

> 정리: 트랙맨을 주 모니터가 아닌 화면에 두는 방법이 "회원 화면을 안 가리는" 가장 확실한 길입니다. 접속 표시를 완전히 없애는 건(연결 관리 창 숨기기) 보안 표시가 사라져 범위 밖이라 쓰지 않습니다.

## 원격으로 "지금 누가 치는지" 조용히 진단하기

원격접속한 상태에서 PowerShell 에 아래를 붙여넣으면, **소리도 안 나고 창도 안 뜨게** 조용히 돕니다.
(원격 세션 안에서 실행하므로, 혹시 잠깐 깜빡여도 타석의 회원 화면엔 안 보입니다.)

```
powershell -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File "C:\golfpt-sync\player-diag.ps1" -Watch 240 -Quiet
```

- 설치 스크립트가 `C:\golfpt-sync\player-diag.ps1` 를 미리 받아 둡니다. (없으면 remote-setup 을 다시 실행)
- 화면에 "시간 ~ 이름" 예약 표시가 새로 뜨면 그 순간을 조용히 진단하고, 이어서 샷이 들어와 3분 조용해지면 한 번 더 진단합니다.
- 결과: `C:\golfpt-sync\diag\player-diag-*.txt` (`-1-예약화면`, `-2-샷이후`). 맨 아래 **[요약]** 부분을 보내주세요.
- `-Quiet` 모드는 **소리·창·사용자 창 조작이 전혀 없습니다.** 멈추려면 작업 관리자에서 powershell 을 끝냅니다.

## 안전·개인정보

- RustDesk 는 숨기지 않고 정상 설치됩니다(작업표시줄 아이콘·서비스). 대표님이 쓰는 도구이니 투명하게 둡니다.
- 비밀번호는 길고 추측 어렵게. 타석 화면엔 회원 이름·예약이 보일 수 있으니 ID·비밀번호를 아무에게도 알려주지 마세요.
- 진단 결과 파일에서는 전화번호·이메일·비밀번호 값이 가려집니다. 카카오톡·브라우저 같은 개인용 프로그램 글자는 읽지 않습니다.
- 더 엄격히 하려면: RustDesk 설정에서 접속 허용을 비밀번호 전용으로 두고, 중계 서버를 직접 운영하는 방법이 있습니다. 필요하시면 안내하겠습니다.

## 안 될 때

- "connection is not allowed / log in" 오류: 접속하는 폰·노트북의 RustDesk 앱에서 로그인하지 않은 것입니다. 위 접속 안내대로 로그인 후 다시 접속하세요.
- 바탕화면 RustDesk 아이콘은 지워도 됩니다. 원격접속은 백그라운드 서비스로 계속 돌아갑니다(회원이 누르지 않게 지우는 걸 권장).

- 설치가 확인되지 않으면 https://rustdesk.com 에서 직접 설치한 뒤 스크립트를 다시 실행하세요.
- 비밀번호 자동 설정이 안 됐다고 나오면, RustDesk 창 왼쪽 아래 **☰ → 설정 → 보안 → "영구 비밀번호"** 에서 직접 정하면 됩니다.
- 접속이 안 되면 PC가 켜져 있고 인터넷에 연결돼 있는지, RustDesk 가 실행 중인지(작업표시줄 아이콘) 확인하세요.
