# 3번룸 PC 에이전트 설치 — 순서대로 따라하기 (상세판)

> 소요 약 15분. 순서 건너뛰지 말고 1번부터.
> 트랙맨 프로그램(TPS)은 안 건드립니다 — 켜져 있든 꺼져 있든 무관.

---

## 1단계. 옛 에이전트 끄고 지우기 (가짜 샷 원인 제거)

### 1-1. 돌고 있는 옛 에이전트 끄기
1. 키보드에서 **Ctrl + Shift + Esc** 동시에 누르기 → **작업 관리자** 열림
2. 창이 작게 나오면 왼쪽 아래 **"자세히"** 클릭
3. **"프로세스"** 탭에서 목록을 훑으며 아래 이름 찾기:
   - **Node.js JavaScript Runtime** (또는 node.exe)
   - **Microsoft Windows Based Script Host** (wscript)
4. 있으면 하나씩 클릭 → 오른쪽 아래 **"작업 끝내기"**. 여러 개면 전부.
5. 없으면 → 이미 꺼진 것. 다음으로.

### 1-2. 자동시작 잔재 삭제
1. 키보드 **Win + R** → 작은 실행창 뜸
2. `shell:startup` 입력 → **확인**
3. 열린 폴더에 **GolfPT-Agent** 바로가기 있으면 → 삭제
4. 폴더가 비어있으면 → 정상. 창 닫기.

### 1-3. 옛 폴더 삭제
1. 파일 탐색기 → **내 PC** → **로컬 디스크 (C:)**
2. **golfpt-sync** 폴더 있으면 → 폴더째 **삭제** (Shift+Delete 면 완전삭제)
3. 새로 깔 거라 안에 있던 건 다 필요 없음

---

## 2단계. PC 시계 맞추기 (샷 시각 정확하게)

1. **시작 버튼** 클릭 → 그냥 키보드로 `시간` 이라고 입력
2. **"날짜 및 시간 설정"** 클릭
3. 다음 세 가지 확인:
   - **시간 자동으로 설정** → **켬**
   - **표준 시간대 자동으로 설정** → 켬 (또는 수동이면 **(UTC+09:00) 서울** 인지 확인)
4. 아래로 내려 **"지금 동기화"** 버튼 클릭
5. "마지막 성공한 시간 동기화" 가 **방금 시각**으로 바뀌면 성공
6. PC 시계(화면 오른쪽 아래)가 휴대폰 시계와 **분 단위까지 같은지** 눈으로 확인

> 동기화 실패 시: 시작 → `cmd` 입력 → "명령 프롬프트" **우클릭 → 관리자 권한으로 실행** → 검은 창에 `w32tm /resync /force` 입력 + 엔터

---

## 3단계. Node.js 확인 (지난번 설치했으면 1분 컷)

1. **Win + R** → `cmd` 입력 → **확인** → 검은 창 열림
2. `node -v` 입력 + **엔터**
3. 결과 보기:
   - **`v20.11.0`** 같은 v+숫자가 나오면 → ✅ 설치돼 있음. **4단계로**
   - **"...실행할 수 있는 프로그램이 아닙니다"** → ❌ 설치 필요. 아래 3-2로

> ⚠️ 만약 `Welcome to Node.js` 라고 나오고 `>` 만 깜빡이면 — node 안에 들어와버린 것.
> `.exit` 입력 + 엔터로 빠져나온 뒤 다시 `node -v`. (지난번에 여기서 막혔었음!)

### 3-2. 설치 (필요한 경우만)
1. 엣지/크롬 열고 주소창에 `nodejs.org` 입력
2. 초록색 큰 버튼 (**LTS** 표시) 클릭 → 다운로드
3. 받은 파일 실행 → 나오는 창마다 **Next** → **Install** → **Finish** (아무 것도 바꾸지 말 것)
4. **열려있던 검은 창 모두 닫고**, 새로 Win+R → cmd → `node -v` → 버전 나오면 성공

---

## 4단계. 새 에이전트 파일 받기

1. 엣지/크롬에서 `github.com/wellnessmode/Golf_PT_collabo` 접속
2. 초록색 **"<> Code"** 버튼 클릭 → 맨 아래 **"Download ZIP"** 클릭
3. 다운로드 끝나면 파일 탐색기 → **다운로드** 폴더
4. **Golf_PT_collabo-main.zip** 우클릭 → **"압축 풀기..."** → **압축 풀기**
5. 풀린 **Golf_PT_collabo-main** 폴더 → 그 안의 **agent** 폴더 열기
6. 이 안의 파일들을 다음 단계에서 복사할 것. 창 그대로 두기.

---

## 5단계. C:\golfpt-sync 폴더 만들고 파일 넣기

1. 파일 탐색기 새 창 → **내 PC** → **로컬 디스크 (C:)**
2. 빈 곳 **우클릭 → 새로 만들기 → 폴더** → 이름: `golfpt-sync` (영문 그대로)
3. 4단계의 **agent 폴더** 창으로 가서 **Ctrl + A** (전체 선택) → **Ctrl + C** (복사)
4. **C:\golfpt-sync** 폴더 열고 **Ctrl + V** (붙여넣기)
5. 다음 파일들이 보이면 OK:
   ```
   agent.js          ftmf-parser.js      config.sample.json
   start-hidden.vbs  설치_자동시작.bat    상태확인.bat
   중지.bat          자동시작_해제.bat    (README, 매뉴얼 등)
   ```

---

## 6단계. config.json 만들기 (이름만 바꾸면 끝)

**키 값은 전부 미리 채워져 있어서 내용 수정 필요 없음.** 이름만 바꾸면 됩니다.

### 6-1. 파일 확장명 보이게 하기 (실수 방지)
1. C:\golfpt-sync 폴더 상단 메뉴 **"보기"** 클릭
2. **"표시"** → **"파일 확장명"** 체크
   (윈도10이면: 보기 탭 → "파일 확장명" 체크박스)

### 6-2. 복사 후 이름 바꾸기
1. **config.sample.json** 클릭 → **Ctrl + C** → **Ctrl + V**
   → "config.sample - 복사본.json" 생김
2. 그 복사본 **우클릭 → 이름 바꾸기**
3. 이름 전체를 지우고 정확히 이렇게 입력: `config.json`
4. 엔터 → "확장명을 변경하면..." 경고 나오면 **예**

> ✅ 최종 확인: 폴더에 **config.sample.json** 과 **config.json** 둘 다 있어야 함

---

## 7단계. 설치 실행 (더블클릭 한 번)

1. **설치_자동시작.bat** 더블클릭
2. 파란 창 **"Windows의 PC 보호"** 가 뜨면:
   → **"추가 정보"** 클릭 → **"실행"** 클릭 (우리가 만든 파일이라 안전)
3. 검은 창에 다음이 차례로 나오는지 확인:
   ```
   [완료] 자동시작 등록됨.
          이제 PC 를 켤 때마다 에이전트가 창 없이 자동 실행됩니다.
   지금 바로 실행할까요? 아무 키나 누르면 백그라운드로 시작합니다.
   ```
4. **아무 키나 누르기** (스페이스바)
5. `[실행됨] 에이전트가 백그라운드에서 동작 중입니다.` 확인 → 창 닫기

> ❌ "[오류] Node.js 가 설치되어 있지 않습니다" → 3단계 다시
> ❌ "[주의] config.json 이 없습니다" → 6단계 다시 (이름 정확히 config.json 인지)

---

## 8단계. 동작 확인 (PC에서)

1. **상태확인.bat** 더블클릭
2. 확인할 것 세 가지:
   - `상태 : [ 실행 중 ]` ← 에이전트 살아있음
   - 로그에 `=== Golf PT Bay Agent 시작 ===` 보임
   - 로그에 **`✓ PC 시계 정확`** 보임
     (🚨 "N분 어긋남" 나오면 → 2단계 시계 다시 맞추고, 중지.bat → 설치_자동시작.bat 재실행)
3. 아무 키 눌러 창 닫기

---

## 9단계. 실전 테스트 (휴대폰 + 트랙맨)

1. 휴대폰에서 앱 열기 → **새로고침** (최신 버전 받기)
2. **🏌️ 수업 센터** 들어가기
3. ⚠️ 화면에 **"🔇 수신 정지"** 빨간 표시가 있으면 → **"▶ 수신 재개"** 버튼 누르기
   (어제 가짜 샷 막느라 잠가둔 것 — 풀어야 새 샷이 보임)
4. **🎯 라이브 수업** → 회원 선택 (테스트면 로버트) → **3번룸** 선택
5. 트랙맨에서 **공 1개 치기**
6. 5~10초 안에 휴대폰 베이 카드에 샷이 **"방금"** 으로 뜨면 → 🎉 **완성**

---

## 10단계. 마지막 — 재부팅 테스트 (자동시작 확인)

1. PC **다시 시작**
2. 부팅 완료 후 (아무것도 안 해도) **상태확인.bat** 더블클릭
3. `상태 : [ 실행 중 ]` 이면 → 이제부터 **PC만 켜지면 전부 자동**. 끝!

## 문제 생겼을 때

| 증상 | 해결 |
|---|---|
| 공 쳤는데 폰에 안 뜸 | ① 앱의 🔇 수신 정지 풀었는지 ② 상태확인.bat → [실행 중]인지 ③ 활성세션(회원 배정) 했는지 |
| 상태확인 → [중지됨] | 설치_자동시작.bat 다시 더블클릭 |
| 시계 어긋남 경고 | 2단계 다시 → 중지.bat → 설치_자동시작.bat |
| 가짜 샷 또 들어옴 | 폰 앱 수업 센터 → 🔇 샷 수신 일시정지 누르고 연락 |
| bat 파일이 메모장으로 열림 | 우클릭 → 연결 프로그램 → 기타 앱 → Windows 명령 처리기 |
| 전부 멈추고 싶음 | 자동시작_해제.bat 더블클릭 |

문제 시 **agent.log** (C:\golfpt-sync 안) 마지막 부분 사진 찍어 공유.

## 참고 (안심 포인트)

- 에이전트는 트랙맨 폴더를 **읽기만** 합니다. 삭제·수정·이동 절대 없음.
- **PC의 영상 원본은 어떤 경우에도 지우지 않습니다.**
- 트랙맨 코리아가 원격 점검해도 TPS는 평소와 100% 동일하게 보입니다.
