# 3번룸 PC — 에이전트 설치 매뉴얼 (한 장)

목적: 트랙맨이 만드는 샷 데이터(.ftmf)·영상을 우리 앱으로 자동 동기화.
원칙: **트랙맨 프로그램(TPS)은 절대 건드리지 않음** — 우리 파일만 읽음.
소요: 약 10분.

---

## 0. 시작 전 준비 (체크리스트)

- [ ] 노트북 또는 USB에 `agent` 폴더 통째로 복사해 옴
      (또는 PC에서 `git clone` 또는 `Code → Download ZIP`로 받기)
- [ ] 관리자 비밀번호 알고 있음 (앱 / PC)
- [ ] 휴대폰 핫스팟 또는 스튜디오 와이파이 연결 가능

---

## 1. 옛 에이전트 흔적 제거 (이전에 깐 게 있다면)

작업표시줄 검색 → `golfpt` 또는 `node` 검색해서 백그라운드 실행 중이면 작업관리자(Ctrl+Shift+Esc)에서 모두 종료.

선택: 옛 폴더(`C:\golfpt-sync\` 등) 있으면 폴더째 삭제. 새로 깔 거라 깨끗이.

**시작프로그램 자동시작 잔재 제거:**
1. `Win + R` → `shell:startup` → 엔터
2. 열린 폴더에서 `GolfPT-Agent.lnk` 보이면 → **삭제**

---

## 2. Node.js 설치 (이미 있으면 건너뛰기)

1. 브라우저에서 `nodejs.org` 접속
2. **LTS** 버튼(왼쪽 큰 버튼) 클릭 → 다운로드 → 기본 설정으로 설치 끝까지 `다음`
3. 확인: `Win + R` → `cmd` → 엔터 → `node -v` → `v20.x.x` 같은 게 뜨면 OK

---

## 3. 에이전트 폴더 배치

`C:\golfpt-sync\` 폴더를 만들고, 아래 파일들 그대로 복사:

```
C:\golfpt-sync\
  agent.js
  ftmf-parser.js
  config.sample.json
  start-hidden.vbs
  설치_자동시작.bat
  상태확인.bat
  중지.bat
  자동시작_해제.bat
```

**※ 한글 폴더명은 피하고, `Documents` 안 같은 위치도 피하기.**
       (권한 충돌 잦음)

## 4. config.json 작성 (가장 중요)

같은 폴더에 `config.sample.json`을 **복사 → 이름을 `config.json`** 로 바꾸고 메모장으로 열어 채움:

```json
{
  "SUPABASE_URL": "https://cacytkmijttyeasmhvhq.supabase.co",
  "SUPABASE_ANON_KEY": "(앱 config.js 의 anon key 그대로)",
  "R2_WORKER_URL": "https://golf-pt-storage.ceo-fc9.workers.dev",
  "R2_API_KEY": "national_gym-golf-pt-qwpiefjwofjwioefhlkjd",
  "watchDirs": [
    "C:\\ProgramData\\TrackMan\\TrackMan Performance Studio\\Data"
  ],
  "bayMap": { "24240089": "bay3" },
  "uploadVideo": true,
  "intervalSec": 5,
  "processExisting": false,
  "backfillMinutes": 0,
  "verbose": false
}
```

**확인 포인트:**
- `bayMap` 의 `"24240089"` = 3번룸 PC 의 트랙맨 시리얼.
  → 확인 방법: 트랙맨 TPS 켜고 `Settings → About` → Tracking Unit 번호.
- `processExisting: false` ← 옛날 ftmf 파일 무시. **반드시 false.**
- 따옴표·쉼표 위치 그대로 유지 (json 문법 깨지면 시작 안 됨).

저장.

## 5. PC 시계 동기화 (필수)

샷 시각이 정확해지도록 한 번 맞춰둡니다.

1. 시작 → "시간" 검색 → **날짜 및 시간 설정**
2. **시간 자동 설정 켬** / **표준시간대 자동 설정 켬** / **(UTC+09:00) 서울** 확인
3. **지금 동기화** 클릭 → "마지막 성공한 시간 동기화" 가 방금으로 갱신되면 OK

안 되면 관리자 cmd:
```
w32tm /resync /force
```

---

## 6. 자동시작 설치 — 한 번에

`C:\golfpt-sync\설치_자동시작.bat` **더블클릭**.

자동으로:
- Node.js / config.json 점검
- 윈도 시작프로그램 등록 → **부팅 시마다 창 없이 자동 실행**
- 끝에 "지금 실행?" → 아무 키 누르면 백그라운드 가동

**창이 사라지면 성공.** 이후 PC 만 켜지면 자동.

---

## 7. 동작 확인

`C:\golfpt-sync\상태확인.bat` **더블클릭**.

다음이 모두 보여야 성공:

- `상태 : [ 실행 중 ]`
- 로그 마지막 줄에 `✓ PC 시계 정확` (또는 `+1초` 등 5초 이내 차이)
- `=== Golf PT Bay Agent 시작 ===` 라인
- `bayMap = {"24240089":"bay3"}` 가 본인 PC 시리얼과 일치

**실전 테스트:**
1. 휴대폰에서 우리 앱 열기 → 🏌️ 수업 센터 → 🎯 라이브 수업 → 회원 배정 → 3번룸 선택
2. 트랙맨에서 공 한 발 → 5~10초 안에 라이브 화면 베이카드 또는 샷 로그에 "방금" 표시되면 **완성**

---

## 8. 문제 시 빠른 조치

| 증상 | 조치 |
|---|---|
| 상태확인에 "중지됨" | `설치_자동시작.bat` 다시 더블클릭 |
| 시계 어긋남 경고 | 5번 단계 시계 동기화 다시 |
| 샷이 폰에 안 뜨는데 로그엔 ✓ 떠 있음 | 폰에서 앱 → 🏌️ 수업 센터 → **🔇 수신 정지** 켜져 있는지 확인. 풀기 |
| 가짜/원치 않는 샷 들어옴 (긴급) | 폰 앱에서 **🔇 샷 수신 일시정지** 클릭 → 원인 찾는 동안 차단 |
| 그래도 새 샷 자꾸 들어옴 | `중지.bat` 으로 에이전트 멈추고 / `자동시작_해제.bat` |

---

## 9. 운영 흐름 (이후 매일)

PC 부팅(자동 로그인) → 에이전트 백그라운드 자동 실행 (창 안 보임)
→ 프로/트레이너는 폰만 만지면 됨.

PC 에서 손 댈 일: **없음.**

---

## 참고

- 에이전트는 트랙맨 `Data` 폴더를 **읽기 전용**으로만 봅니다 (삭제·이동·수정 절대 X).
- 트랙맨 영상은 R2(클라우드)로 사본을 떠 두지만, **PC 원본은 절대 안 지웁니다.**
- 트랙맨 코리아가 원격으로 PC 만져도 TPS 는 평소와 동일하게 보입니다 (개입·흔적 0).

문제 생기면 `agent.log` 마지막 30줄 캡처해서 공유.
